**齐次方程：**

齐次方程是微分方程中一类重要的一阶微分方程，核心特征是方程可转化为关于变量比值的函数形式，求解思路主要是通过变量代换将其转化为可分离变量的微分方程，具体知识点如下：

**一、齐次方程的定义**

对于一阶微分方程 $$\frac{dy}{dx} = f(x,y)$$，若函数 $$f(x,y)$$ 满足 $$f(tx,ty) = f(x,y)$$（其中 $$t \neq 0$$ 为任意常数），则称该方程为齐次方程。

简单来说，齐次方程的右端函数 $$f(x,y)$$ 是零次齐次函数，即分子分母的各项次数相同（这里的"次数"指x和y的总次数，例如 $$\frac{x^{2} + xy}{y^{2}}$$ 中，分子各项次数均为2，分母次数为2，满足齐次条件）。

**二、齐次方程的判定方法**

判定一个一阶微分方程是否为齐次方程，主要有两种方法：

定义法：验证 $$f(tx,ty) = f(x,y)$$ 是否成立。若成立，则为齐次方程；否则不是。

形式法：将方程整理为 $$\frac{dy}{dx} = \varphi\left( \frac{y}{x} \right)$$ 的形式，若能整理成此形式，则为齐次方程。绝大多数齐次方程都可通过代数变形，转化为这种关于 $$\frac{y}{x}$$ 的函数形式。

**三、齐次方程的求解步骤**

齐次方程的核心求解思路是"变量代换"，将关于x、y的方程转化为关于t、x（或t、y）的可分离变量方程，具体步骤如下：

变量代换：令 $$t = \frac{y}{x}$$（即 $$y = tx$$），其中t是关于x的函数，因此对x求导可得 $$\frac{dy}{dx} = t + x\frac{dt}{dx}$$。

代入化简：将 $$y = tx$$ 和 $$\frac{dy}{dx} = t + x\frac{dt}{dx}$$ 代入原齐次方程，化简后可消去y，得到仅含t和x的可分离变量方程。

分离变量并积分：将方程整理为 $$\frac{dt}{\varphi(t) - t} = \frac{dx}{x}$$ 的形式（其中 $$\frac{dy}{dx} = \varphi\left( \frac{y}{x} \right) = \varphi(t)$$），两边分别对t和x积分，得到积分结果。

回代还原：将 $$t = \frac{y}{x}$$ 代回积分结果，整理后得到原齐次方程的通解（若有初始条件，可进一步求出特解）。

除了标准齐次方程，还有一类特殊的一阶微分方程，本身不是齐次方程，但通过适当的变量代换（平移变换），可转化为齐次方程求解，这类方程称为"可化为齐次的方程"，具体知识点如下：

**四、可化为齐次的方程**

**（一）方程形式**

可化为齐次的方程主要有两种常见形式，核心特征是分子分母均为x、y的一次多项式，具体如下：

基本形式：$$\frac{dy}{dx} = \frac{a_{1}x + b_{1}y + c_{1}}{a_{2}x + b_{2}y + c_{2}}$$，其中 $$c_{1}$$、$$c_{2}$$ 不同时为0（若 $$c_{1} = c_{2} = 0$$，则方程本身就是齐次方程）。

特殊情形：当 $$\frac{a_{1}}{a_{2}} = \frac{b_{1}}{b_{2}} = k$$（即分子分母的一次项系数成比例）时，方程可简化为可分离变量方程，无需转化为齐次方程，后续会单独说明。

**（二）转化条件与平移变换**

对于基本形式 $$\frac{dy}{dx} = \frac{a_{1}x + b_{1}y + c_{1}}{a_{2}x + b_{2}y + c_{2}}$$，转化为齐次方程的关键是"消去常数项 $$c_{1}$$、$$c_{2}$$"，通过平移变换实现：

设平移变换：令 $$x = X + h$$，$$y = Y + k$$，其中h、k为待定常数，目的是让常数项消去。此时 $$dx = dX$$，$$dy = dY$$，方程变为 $$\frac{dY}{dX} = \frac{a_{1}(X + h) + b_{1}(Y + k) + c_{1}}{a_{2}(X + h) + b_{2}(Y + k) + c_{2}}$$。

确定h、k：整理分子分母的常数项，令常数项之和为0，得到关于h、k的二元一次方程组：\
$$\left\{ \begin{array}{r}
a_{1}h + b_{1}k + c_{1} = 0 \\
a_{2}h + b_{2}k + c_{2} = 0
\end{array} \right.\ $$

分情况讨论方程组的解：\
情况1：系数行列式 $$\Delta = \left| \begin{matrix}
a_{1} & b_{1} \\
a_{2} & b_{2}
\end{matrix} \right| = a_{1}b_{2} - a_{2}b_{1} \neq 0$$，方程组有唯一解（h,k），代入后方程化为齐次方程$$\frac{dY}{dX} = \frac{a_{1}X + b_{1}Y}{a_{2}X + b_{2}Y}$$，再按齐次方程求解。

情况2：系数行列式 $$\Delta = 0$$，即 $$\frac{a_{1}}{a_{2}} = \frac{b_{1}}{b_{2}} = k$$，此时令 $$u = a_{2}x + b_{2}y$$，则 $$\frac{du}{dx} = a_{2} + b_{2}\frac{dy}{dx}$$，代入原方程可转化为可分离变量方程，直接求解。

**（三）求解步骤（以** $$\Delta \neq 0$$ **为例）**

解方程组$$\left\{ \begin{array}{r}
a_{1}h + b_{1}k + c_{1} = 0 \\
a_{2}h + b_{2}k + c_{2} = 0
\end{array} \right.\ $$，求出h、k的值。

作平移变换 $$x = X + h$$，$$y = Y + k$$，将原方程转化为齐次方程 $$\frac{dY}{dX} = \frac{a_{1}X + b_{1}Y}{a_{2}X + b_{2}Y}$$。

按齐次方程的求解步骤（令 $$t = \frac{Y}{X}$$，变量代换、分离积分、回代），求出关于X、Y的通解。

将 $$X = x - h$$，$$Y = y - k$$ 代回，得到原方程的通解；若有初始条件，可进一步求出特解。

**（四）求解示例**

求解方程 $$\frac{dy}{dx} = \frac{x - y + 1}{x + y - 3}$$，步骤如下：

判断类型：该方程符合可化为齐次的方程基本形式，$$c_{1} = 1$$、$$c_{2} = - 3$$ 不同时为0，计算系数行列式 $$\Delta = \left| \begin{matrix}
1 & - 1 \\
1 & 1
\end{matrix} \right| = 1 \times 1 - 1 \times ( - 1) = 2 \neq 0$$，可通过平移变换转化为齐次方程。

求h、k：解方程组 $$\left\{ \begin{array}{r}
h - k + 1 = 0 \\
h + k - 3 = 0
\end{array} \right.\ $$，两式相加得 $$2h - 2 = 0$$，即 $$h = 1$$，代入得 $$k = 2$$。

平移变换：令 $$x = X + 1$$，$$y = Y + 2$$，则 $$\frac{dy}{dx} = \frac{dY}{dX}$$，方程化为 $$\frac{dY}{dX} = \frac{(X + 1) - (Y + 2) + 1}{(X + 1) + (Y + 2) - 3} = \frac{X - Y}{X + Y}$$，即为齐次方程。

求解齐次方程：令 $$t = \frac{Y}{X}$$，则 $$Y = tX$$，$$\frac{dY}{dX} = t + X\frac{dt}{dX}$$，代入得 $$t + X\frac{dt}{dX} = \frac{1 - t}{1 + t}$$。

分离积分：整理得 $$\frac{1 + t}{1 - 2t - t^{2}}dt = \frac{dX}{X}$$，两边积分，左边令 $$u = 1 - 2t - t^{2}$$，则 $$du = ( - 2 - 2t)dt = - 2(1 + t)dt$$，积分得 $$- \frac{1}{2}\ln|u| = \ln|X| + C_{1}$$，即 $$\ln|1 - 2t - t^{2}| = - 2\ln|X| + C$$（$$C = - 2C_{1}$$），化简得 $$1 - 2t - t^{2} = \frac{C}{X^{2}}$$。

回代还原：先将 $$t = \frac{Y}{X}$$ 代入，得 $$X^{2} - 2XY - Y^{2} = C$$，再将 $$X = x - 1$$，$$Y = y - 2$$ 代入，得到原方程通解 $$(x - 1)^{2} - 2(x - 1)(y - 2) - (y - 2)^{2} = C$$（C为任意常数）。

**（五）注意事项**

平移变换的核心是"消去常数项"，h、k的求解必须通过解二元一次方程组，确保变换后方程无常数项，才能转化为齐次方程。

当 $$\Delta = 0$$ 时，不可强行用平移变换，需采用"令 $$u = a_{2}x + b_{2}y$$"的代换，直接转化为可分离变量方程，避免出错。

求解完成后，务必将 $$X = x - h$$、$$Y = y - k$$ 回代，还原为x、y的关系式，这是容易遗漏的步骤。

**一阶线性微分方程：**

一阶线性微分方程是另一类重要的一阶微分方程，核心特征是未知函数及其导数均为一次项，无乘积或非线性项，求解核心方法为"常数变易法"，具体知识点及求法如下：

**一、一阶线性微分方程的定义与标准形式**

若一阶微分方程可整理为 $$\frac{dy}{dx} + P(x)y = Q(x)$$ 的形式，则称该方程为一阶线性微分方程。

关键说明：

标准形式的核心特征：未知函数y的导数 $$\frac{dy}{dx}$$ 是一次项，y本身也是一次项，不含 $$y^{2}$$、$$y\frac{dy}{dx}$$ 等非线性项。

分类：\
非齐次线性方程：当 $$Q(x) \neq 0$$ 时，方程为一阶非齐次线性微分方程（标准形式如上）。

齐次线性方程：当$$Q(x) = 0$$ 时，方程变为 $$\frac{dy}{dx} + P(x)y = 0$$，称为对应于非齐次方程的一阶齐次线性微分方程（注意：此处的"齐次"与前文齐次方程定义不同，仅指未知函数及其导数的次数均为1）。

示例：$$\frac{dy}{dx} + 2xy = x^{2}$$（非齐次，$$P(x) = 2x$$，$$Q(x) = x^{2}$$）；$$\frac{dy}{dx} - \frac{1}{x}y = 0$$（齐次，$$P(x) = - \frac{1}{x}$$，$$Q(x) = 0$$）。

**二、一阶线性微分方程的求解方法**

求解遵循"先求齐次方程通解，再用常数变易法求非齐次方程通解"的思路，具体步骤如下：

**（一）第一步：求解对应齐次方程**$$\frac{dy}{dx} + P(x)y = 0$$

该方程为可分离变量方程，求解步骤简单：

分离变量：将方程整理为 $$\frac{dy}{y} = - P(x)dx$$（注意：$$y \neq 0$$，后续需验证 $$y = 0$$ 是否为解）。

两边积分：$$\int\frac{1}{y}dy = - \int P(x)dx$$，得 $$\ln|y| = - \int P(x)dx + C_{1}$$（$$C_{1}$$ 为积分常数）。

化简通解： exponentiate 两边，得齐次方程通解 $$y = Ce^{- \int P(x)dx}$$，其中 $$C = \pm e^{C_{1}}$$ 为任意常数（包含 $$y = 0$$ 的情况，此时 $$C = 0$$）。

**（二）第二步：用常数变易法求非齐次方程** $$\frac{dy}{dx} + P(x)y = Q(x)$$ **的通解**

常数变易法的核心思想：将齐次方程通解中的常数C，替换为关于x的未知函数 $$C(x)$$，代入非齐次方程，求解 $$C(x)$$，进而得到非齐次方程的通解。具体步骤：

设非齐次方程的解：令 $$y = C(x)e^{- \int P(x)dx}$$（将齐次通解的C换为 $$C(x)$$）。

求导代入：对y求导，得 $$\frac{dy}{dx} = C^{\prime}(x)e^{- \int P(x)dx} + C(x) \cdot \left( - P(x)e^{- \int P(x)dx} \right)$$，将y和 $$\frac{dy}{dx}$$ 代入非齐次方程。

化简求解 $$C(x)$$：代入后化简，可消去含 $$C(x)$$ 的项，得到 $$C^{\prime}(x)e^{- \int P(x)dx} = Q(x)$$，整理得 $$C^{\prime}(x) = Q(x)e^{\int P(x)dx}$$；两边积分，得 $$C(x) = \int Q(x)e^{\int P(x)dx}dx + C$$（C为任意常数）。

得到通解：将 $$C(x)$$ 代回步骤1的假设，得到非齐次方程的通解：\
$$y = e^{- \int P(x)dx}\left( \int Q(x)e^{\int P(x)dx}dx + C \right)$$

记忆技巧：通解可记为"齐次通解 ×（非齐次项×积分因子积分 + 常数）"，其中 $$e^{\int P(x)dx}$$ 称为积分因子，记为 $$\mu(x) = e^{\int P(x)dx}$$，通解也可写成 $$y\mu(x) = \int Q(x)\mu(x)dx + C$$，更易计算。

**三、注意事项**

必须先将方程化为标准形式 $$\frac{dy}{dx} + P(x)y = Q(x)$$，注意P(x)的符号（易错点：若原方程是 $$\frac{dy}{dx} - P(x)y = Q(x)$$，则标准形式中 $$P(x)$$ 为负）。

积分因子 $$\mu(x) = e^{\int P(x)dx}$$ 计算时，无需加积分常数（加常数会被后续的任意常数C吸收，不影响通解）。

常数变易法是核心，不可直接套用齐次方程通解；若 $$Q(x) = 0$$，则退化为齐次方程，通解即为 $$y = Ce^{- \int P(x)dx}$$。

验证特殊解：分离变量时若除以y，需验证 $$y = 0$$ 是否为原方程的解，若满足则需纳入通解（通常已包含在 $$C = 0$$ 的情况中）。

**伯努利方程：**

伯努利方程是一阶非线性微分方程，但可通过变量代换转化为一阶线性微分方程求解，其核心特征是未知函数y的次数不为1，与前文一阶线性微分方程联系紧密，具体知识点及求法如下：

**一、伯努利方程的定义与标准形式**

若一阶微分方程可整理为 $$\frac{dy}{dx} + P(x)y = Q(x)y^{n}$$ 的形式（其中 $$n \neq 0,1$$ 为常数），则称该方程为伯努利方程。

关键说明：

核心特征：方程右端含未知函数y的n次项 $$Q(x)y^{n}$$，当 $$n = 0$$ 时，方程变为 $$\frac{dy}{dx} + P(x)y = Q(x)$$，即一阶非齐次线性微分方程；当 $$n = 1$$ 时，方程变为 $$\frac{dy}{dx} + \lbrack P(x) - Q(x)\rbrack y = 0$$，即一阶齐次线性微分方程，因此伯努利方程是一阶线性微分方程的推广。

非线性本质：因含 $$y^{n}$$（$$n \neq 1$$）项，方程为非线性微分方程，但通过变量代换可转化为线性方程，这是其求解核心。

**二、伯努利方程的求解方法**

求解核心思路：通过变量代换消去非线性项 $$y^{n}$$，将伯努利方程转化为一阶线性微分方程，再利用常数变易法求解，具体步骤如下：

变形整理：将伯努利方程 $$\frac{dy}{dx} + P(x)y = Q(x)y^{n}$$ 两边同时除以 $$y^{n}$$（注意：$$y \neq 0$$，后续需验证 $$y = 0$$ 是否为解），得到：\
$$y^{- n}\frac{dy}{dx} + P(x)y^{1 - n} = Q(x)$$

变量代换：令 $$z = y^{1 - n}$$（核心代换，目的是将非线性项转化为一次项），对x求导得：\
$$\frac{dz}{dx} = (1 - n)y^{- n}\frac{dy}{dx}$$，即 $$y^{- n}\frac{dy}{dx} = \frac{1}{1 - n}\frac{dz}{dx}$$

转化为线性方程：将上述代换代入步骤1的变形方程，整理得一阶线性微分方程：\
$$\frac{dz}{dx} + (1 - n)P(x)z = (1 - n)Q(x)$$\
此时方程符合标准形式 $$\frac{dz}{dx} + P_{1}(x)z = Q_{1}(x)$$，其中 $$P_{1}(x) = (1 - n)P(x)$$，$$Q_{1}(x) = (1 - n)Q(x)$$。

求解线性方程：利用一阶线性微分方程的通解公式（常数变易法推导的公式），求出z关于x的通解。

回代还原：将 $$z = y^{1 - n}$$ 代回z的通解，整理后得到原伯努利方程的通解；若有初始条件，可进一步求出特解，同时验证 $$y = 0$$ 是否为解（若满足则纳入通解）。

**三、注意事项**

明确n的取值：必须满足 $$n \neq 0,1$$，若 $$n = 0$$ 或 $$n = 1$$，方程退化为一阶线性微分方程，直接按线性方程求解即可。

变量代换的关键：牢记代换式 $$z = y^{1 - n}$$，求导时注意链式法则，避免计算错误（易错点：漏乘 $$(1 - n)$$）。

验证特殊解：两边除以 $$y^{n}$$ 时，默认 $$y \neq 0$$，需单独验证 $$y = 0$$ 是否为原方程的解，若满足则需加入通解。

衔接线性方程：转化后的线性方程需整理为标准形式$$\frac{dz}{dx} + P_{1}(x)z = Q_{1}(x)$$，注意 $$P_{1}(x)$$ 的符号，避免代入通解公式时出错。

**可降阶的高阶微分方程：**

可降阶的高阶微分方程（通常指二阶及以上），核心求解思路是通过适当的变量代换，将高阶方程转化为低阶微分方程（一阶或二阶可解形式），再逐步求解。常见类型有三种，分别对应不同的方程特征和代换方法，具体知识点如下：

**一、可降阶高阶微分方程的定义**

高阶微分方程（阶数≥2）中，若通过变量代换能降低方程的阶数（如将二阶降为一阶），且降阶后的方程可利用前文所学的一阶微分方程求解方法（分离变量、线性方程、伯努利方程等）求解，则称此类方程为可降阶的高阶微分方程。

核心原则：根据方程中"缺项"（不含未知函数y、不含y的导数等）特征，选择对应的变量代换，核心是"降阶"，将复杂的高阶方程转化为已学的低阶方程。

**二、常见类型及求解方法（以二阶为例，可推广至更高阶）**

二阶可降阶微分方程主要有三种常见类型，每种类型的求解方法不同，重点掌握变量代换的技巧：

**（一）类型1：**$$y^{''} = f(x)$$**（不含y和**$$y^{\prime}$$**，仅含x）**

这类方程是最简单的可降阶高阶方程，核心特征是仅含x和最高阶导数$$y^{''}$$，求解方法为"逐次积分法"，直接通过两次积分降阶求解。

第一次积分：对$$y^{''} = f(x)$$两边同时对x积分，得到一阶导数$$y^{\prime} = \int f(x)dx + C_{1}$$（$$C_{1}$$为任意常数）。

第二次积分：对$$y^{\prime} = \int f(x)dx + C_{1}$$再次对x积分，得到原方程的通解$$y = \int\left( \int f(x)dx + C_{1} \right)dx + C_{2}$$（$$C_{1},C_{2}$$为任意常数）。

示例：求解$$y^{''} = x + \sin x$$，步骤如下：

第一次积分：$$y^{\prime} = \int(x + \sin x)dx + C_{1} = \frac{1}{2}x^{2} - \cos x + C_{1}$$。

第二次积分：$$y = \int\left( \frac{1}{2}x^{2} - \cos x + C_{1} \right)dx + C_{2} = \frac{1}{6}x^{3} - \sin x + C_{1}x + C_{2}$$，即为通解（$$C_{1},C_{2}$$为任意常数）。

**（二）类型2：**$$y^{''} = f(x,y^{\prime})$$**（不含y，含x和**$$y^{\prime}$$**）**

核心特征：方程中不含未知函数y，仅含x和一阶导数$$y^{\prime}$$、二阶导数$$y^{''}$$，求解思路是"令$$p = y^{\prime}$$，将二阶导数转化为一阶导数"，降阶为一阶微分方程。

变量代换：令$$p = y^{\prime}$$，则二阶导数$$y^{''} = \frac{dp}{dx}$$（因p是x的函数，导数对x求导）。

降阶转化：将$$p = y^{\prime}$$和$$y^{''} = \frac{dp}{dx}$$代入原方程，得到关于x和p的一阶微分方程$$\frac{dp}{dx} = f(x,p)$$。

求解一阶方程：利用前文所学的一阶微分方程求解方法（分离变量、线性方程等），求出p关于x的通解$$p = \varphi(x,C_{1})$$。

回代还原：因$$p = y^{\prime}$$，即$$\frac{dy}{dx} = \varphi(x,C_{1})$$，两边积分得到原方程的通解$$y = \int\varphi(x,C_{1})dx + C_{2}$$（$$C_{1},C_{2}$$为任意常数）。

**（三）类型3：**$$y^{''} = f(y,y^{\prime})$$**（不含x，含y和**$$y^{\prime}$$**）**

核心特征：方程中不含自变量x，仅含未知函数y和一阶导数$$y^{\prime}$$、二阶导数$$y^{''}$$，求解思路是"令$$p = y^{\prime}$$，将二阶导数转化为p对y的导数"，降阶为一阶微分方程。

变量代换：令$$p = y^{\prime}$$，利用链式法则，将二阶导数转化为p对y的导数：$$y^{''} = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p \cdot \frac{dp}{dy}$$（关键：将对x的导数转化为对y的导数，适配"不含x"的特征）。

降阶转化：将$$p = y^{\prime}$$和$$y^{''} = p \cdot \frac{dp}{dy}$$代入原方程，得到关于y和p的一阶微分方程$$p \cdot \frac{dp}{dy} = f(y,p)$$。

求解一阶方程：利用分离变量法等，求出p关于y的通解$$p = \varphi(y,C_{1})$$（或隐函数形式）。

回代还原：因$$p = \frac{dy}{dx}$$，即$$\frac{dy}{dx} = \varphi(y,C_{1})$$，分离变量后积分$$\int\frac{dy}{\varphi(y,C_{1})} = \int dx + C_{2}$$，得到原方程的通解。

**三、注意事项**

判断类型是关键：根据方程中"缺项"特征（不含y、不含x、仅含x），选择对应的变量代换，避免代换错误（如类型3不可用类型2的代换）。

变量代换的细节：类型3中，$$y^{''} = p \cdot \frac{dp}{dy}$$是核心，牢记链式法则的转化，避免误写为$$\frac{dp}{dx}$$。

常数的保留：逐次积分或降阶求解过程中，每次积分都要保留任意常数，最终通解的常数个数等于方程的阶数（二阶方程有2个任意常数）。

特殊解的验证：求解时若出现"除以变量（如p、y）"的操作，需单独验证该变量为0时是否为原方程的解，若满足则纳入通解。

高阶推广：对于三阶及以上可降阶方程（如$$y^{'''} = f(x)$$、$$y^{'''} = f(x,y^{''})$$），可采用类似思路逐次降阶，逐步转化为一阶方程求解。

示例（结合可降阶高阶方程类型3，贴合前文知识点）：求解方程 $$yy^{''} - (y^{\prime})^{2} = 0$$（不含x，属于$$y^{''} = f(y,y^{\prime})$$类型），重点验证特殊解：

变量代换：令$$p = y^{\prime}$$，则$$y^{''} = p \cdot \frac{dp}{dy}$$，代入原方程得 $$y \cdot p \cdot \frac{dp}{dy} - p^{2} = 0$$。

化简过程（出现"除以变量p"的操作）：\
此时方程可提取公因式p，得$$p\left( y \cdot \frac{dp}{dy} - p \right) = 0$$。若直接两边除以p（默认$$p \neq 0$$），会得到 $$y \cdot \frac{dp}{dy} - p = 0$$，进而求解得 $$p = C_{1}y$$，回代后得到通解 $$y = Ce^{C_{1}x}$$（C为任意常数）。

特殊解验证（验证$$p = 0$$是否为原方程的解）：\
当$$p = 0$$时，因$$p = y^{\prime}$$，即$$\frac{dy}{dx} = 0$$，此时$$y^{''} = 0$$。将$$y^{\prime} = 0$$、$$y^{''} = 0$$代入原方程：左边$$y \cdot 0 - 0^{2} = 0$$，右边$$0$$，左右两边相等，说明$$p = 0$$对应的解$$y = C_{2}$$（C_2为任意常数）也是原方程的解。

整合通解：\
验证后发现，$$y = C_{2}$$（常数解）可包含在$$y = Ce^{C_{1}x}$$中（当$$C_{1} = 0$$时，$$y = C$$，与$$y = C_{2}$$一致），因此原方程的通解为$$y = Ce^{C_{1}x}$$（$$C_{1},C$$为任意常数）。

补充说明：该示例清晰体现"除以变量（p）需验证变量为0"的核心------若未验证$$p = 0$$，会遗漏常数解$$y = C_{2}$$；验证后确认其为解，且可纳入通解，确保求解完整。类似地，若求解时除以y（如伯努利方程中除以$$y^{n}$$），需单独验证$$y = 0$$是否满足原方程，避免遗漏特殊解。

**高阶线性微分方程：**

高阶线性微分方程是阶数≥2、未知函数及其各阶导数均为一次项的微分方程，是微分方程的重要分支，核心重点是二阶常系数线性微分方程的求解，其解的结构具有明确规律，具体知识点如下：

**一、高阶线性微分方程的定义与标准形式**

若n阶微分方程可整理为：$$y^{(n)} + a_{1}(x)y^{(n - 1)} + a_{2}(x)y^{(n - 2)} + \cdots + a_{n - 1}(x)y^{\prime} + a_{n}(x)y = f(x)$$，则称该方程为n阶线性微分方程。

关键说明：

核心特征：未知函数y的各阶导数（从1阶到n阶）及y本身均为一次项，不含非线性项（如$$(y^{''})^{2}$$、$$y \cdot y^{\prime}$$等），系数$$a_{1}(x),a_{2}(x),\ldots,a_{n}(x)$$为x的函数（或常数）。

分类：\
非齐次线性方程：当$$f(x) \neq 0$$时，称为n阶非齐次线性微分方程（标准形式如上）。

齐次线性方程：当$$f(x) = 0$$时，方程变为$$y^{(n)} + a_{1}(x)y^{(n - 1)} + \cdots + a_{n}(x)y = 0$$，称为对应于非齐次方程的n阶齐次线性微分方程。

重点研究对象：工程、物理中最常用的是**二阶常系数线性微分方程**（n=2，系数为常数），其形式为：$$y^{''} + py^{\prime} + qy = f(x)$$（p、q为常数），对应齐次方程为$$y^{''} + py^{\prime} + qy = 0$$。

**二、高阶线性微分方程解的结构（以二阶为例，可推广至n阶）**

二阶线性微分方程的解具有明确的结构规律，是求解的核心依据，需重点掌握齐次、非齐次方程解的关系。

**（一）二阶齐次线性微分方程**$$y^{''} + py^{\prime} + qy = 0$$**的解的结构**

叠加原理：若$$y_{1}(x)$$和$$y_{2}(x)$$是该齐次方程的两个解，则$$y = C_{1}y_{1}(x) + C_{2}y_{2}(x)$$（$$C_{1},C_{2}$$为任意常数）也是该方程的解。

通解条件：若$$y_{1}(x)$$和$$y_{2}(x)$$是该齐次方程的**线性无关解**（即不存在常数k，使得$$y_{1}(x) = ky_{2}(x)$$），则$$y = C_{1}y_{1}(x) + C_{2}y_{2}(x)$$是该齐次方程的通解。

线性无关判断：对于两个解$$y_{1}(x)$$和$$y_{2}(x)$$，若其比值$$\frac{y_{1}(x)}{y_{2}(x)} \neq$$常数，则二者线性无关；否则线性相关。

**（二）二阶非齐次线性微分方程**$$y^{''} + py^{\prime} + qy = f(x)$$**的解的结构**

若$$y^{\ast}(x)$$是该非齐次方程的一个**特解**，$$Y(x) = C_{1}y_{1}(x) + C_{2}y_{2}(x)$$是对应齐次方程的通解，则该非齐次方程的通解为：$$y = Y(x) + y^{\ast}(x) = C_{1}y_{1}(x) + C_{2}y_{2}(x) + y^{\ast}(x)$$。

补充：非齐次方程的特解不唯一，但任意两个特解的差，必是对应齐次方程的解。

**三、常数变易法**

常数变易法是求解高阶线性微分方程的核心方法之一，适用于**二阶变系数齐次线性微分方程**和**二阶非齐次线性微分方程**（无论系数是否为常数），核心思想与一阶线性微分方程的常数变易法一致------将齐次方程通解中的任意常数替换为关于x的未知函数，代入方程求解未知函数，进而得到通解。以下重点讲解二阶线性方程中常数变易法的具体应用，分齐次和非齐次两种情况说明：

**（一）适用场景**

二阶变系数齐次线性微分方程：$$y^{''} + P(x)y^{\prime} + Q(x)y = 0$$，若已知该方程的一个非零特解，可通过常数变易法求出另一个线性无关的特解，进而得到齐次方程的通解。

二阶非齐次线性微分方程：$$y^{''} + P(x)y^{\prime} + Q(x)y = f(x)$$，若已知对应齐次方程的通解，可通过常数变易法求出非齐次方程的一个特解，进而得到非齐次方程的通解。

补充说明：对于二阶常系数齐次线性微分方程，优先用"特征方程法"求解（更简便）；常数变易法的核心优势的是适配变系数方程，是通用求解方法。

**（二）核心原理**

1\. 对于二阶齐次线性方程：若已知一个非零特解$$y_{1}(x)$$，假设另一个线性无关的特解为$$y_{2}(x) = C(x)y_{1}(x)$$（将常数C变为x的未知函数$$C(x)$$），代入齐次方程，求解$$C(x)$$，即可得到$$y_{2}(x)$$，进而得到齐次通解$$Y(x) = C_{1}y_{1}(x) + C_{2}y_{2}(x)$$。

2\. 对于二阶非齐次线性方程：若已知对应齐次方程的通解$$Y(x) = C_{1}y_{1}(x) + C_{2}y_{2}(x)$$，假设非齐次方程的特解为$$y^{\ast}(x) = C_{1}(x)y_{1}(x) + C_{2}(x)y_{2}(x)$$（将两个任意常数$$C_{1},C_{2}$$均变为x的未知函数$$C_{1}(x),C_{2}(x)$$），代入非齐次方程，结合线性无关条件列出方程组，求解$$C_{1}(x),C_{2}(x)$$，即可得到特解$$y^{\ast}(x)$$，最终通解为$$y = Y(x) + y^{\ast}(x)$$。

**（三）具体求解步骤（分两种情况）**

**情况1：二阶变系数齐次线性方程（已知一个特解**$$y_{1}(x)$$**）**

假设特解：设另一个线性无关的特解为$$y_{2}(x) = C(x)y_{1}(x)$$，其中$$C(x)$$为关于x的未知函数。

求导代入：对$$y_{2}(x)$$求一阶、二阶导数：\
$$y_{2}^{\prime} = C^{\prime}(x)y_{1}(x) + C(x)y_{1}^{\prime}(x)$$$$y_{2}^{''} = C^{''}(x)y_{1}(x) + 2C^{\prime}(x)y_{1}^{\prime}(x) + C(x)y_{1}^{''}(x)$$将$$y_{2},y_{2}^{\prime},y_{2}^{''}$$代入齐次方程$$y^{''} + P(x)y^{\prime} + Q(x)y = 0$$。

化简求解$$C(x)$$：\
因$$y_{1}(x)$$是齐次方程的解，满足$$y_{1}^{''} + P(x)y_{1}^{\prime} + Q(x)y_{1} = 0$$，代入后可消去含$$C(x)$$的项，得到关于$$C^{\prime}(x)$$的二阶线性方程，令$$z = C^{\prime}(x)$$，转化为一阶可分离变量方程：$$y_{1}(x)z^{\prime} + \lbrack 2y_{1}^{\prime}(x) + P(x)y_{1}(x)\rbrack z = 0$$分离变量积分，得$$z = C_{0}e^{- \int\frac{2y_{1}^{\prime}(x) + P(x)y_{1}(x)}{y_{1}(x)}dx} = \frac{C_{0}}{y_{1}^{2}(x)}e^{- \int P(x)dx}$$（$$C_{0}$$为任意常数），取$$C_{0} = 1$$，积分得$$C(x) = \int\frac{1}{y_{1}^{2}(x)}e^{- \int P(x)dx}dx$$。

得到通解：将$$C(x)$$代回$$y_{2}(x) = C(x)y_{1}(x)$$，得到$$y_{2}(x)$$，齐次方程通解为$$Y(x) = C_{1}y_{1}(x) + C_{2}y_{2}(x)$$（$$C_{1},C_{2}$$为任意常数）。

**情况2：二阶非齐次线性方程（已知对应齐次方程通解**$$Y(x) = C_{1}y_{1}(x) + C_{2}y_{2}(x)$$**）**

假设特解：设非齐次方程的特解为$$y^{\ast}(x) = C_{1}(x)y_{1}(x) + C_{2}(x)y_{2}(x)$$，其中$$C_{1}(x),C_{2}(x)$$为关于x的未知函数。

求导并简化：对$$y^{\ast}(x)$$求一阶导数：\
$$y^{\ast^{\prime}} = C_{1}^{\prime}(x)y_{1}(x) + C_{1}(x)y_{1}^{\prime}(x) + C_{2}^{\prime}(x)y_{2}(x) + C_{2}(x)y_{2}^{\prime}(x)$$为简化计算，令含$$C_{1}^{\prime}(x),C_{2}^{\prime}(x)$$的一次项之和为0，即：$$C_{1}^{\prime}(x)y_{1}(x) + C_{2}^{\prime}(x)y_{2}(x) = 0$$ （辅助条件）此时，一阶导数简化为$$y^{\ast^{\prime}} = C_{1}(x)y_{1}^{\prime}(x) + C_{2}(x)y_{2}^{\prime}(x)$$，再求二阶导数：$$y^{\ast^{''}} = C_{1}^{\prime}(x)y_{1}^{\prime}(x) + C_{1}(x)y_{1}^{''}(x) + C_{2}^{\prime}(x)y_{2}^{\prime}(x) + C_{2}(x)y_{2}^{''}(x)$$

代入求解方程组：将$$y^{\ast},y^{\ast^{\prime}},y^{\ast^{''}}$$代入非齐次方程$$y^{''} + P(x)y^{\prime} + Q(x)y = f(x)$$，结合$$y_{1},y_{2}$$是齐次方程的解，化简后得到第二个方程：$$C_{1}^{\prime}(x)y_{1}^{\prime}(x) + C_{2}^{\prime}(x)y_{2}^{\prime}(x) = f(x)$$。联立辅助条件，得到关于$$C_{1}^{\prime}(x),C_{2}^{\prime}(x)$$的线性方程组：$$\left\{ \begin{array}{r}
C_{1}^{\prime}(x)y_{1}(x) + C_{2}^{\prime}(x)y_{2}(x) = 0 \\
C_{1}^{\prime}(x)y_{1}^{\prime}(x) + C_{2}^{\prime}(x)y_{2}^{\prime}(x) = f(x)
\end{array} \right.\ $$。通过克莱姆法则求解该方程组，需引入朗斯基行列式$$W(x)$$，其定义为：$$W(x) = \left| \begin{matrix}
y_{1}(x) & y_{2}(x) \\
y_{1}^{\prime}(x) & y_{2}^{\prime}(x)
\end{matrix} \right| = y_{1}(x)y_{2}^{\prime}(x) - y_{1}^{\prime}(x)y_{2}(x)$$（因$$y_{1},y_{2}$$线性无关，故$$W(x) \neq 0$$）。最终解得：$$C_{1}^{\prime}(x) = - \frac{y_{2}(x)f(x)}{W(x)},C_{2}^{\prime}(x) = \frac{y_{1}(x)f(x)}{W(x)}$$。

积分求未知函数：对$$C_{1}^{\prime}(x),C_{2}^{\prime}(x)$$分别积分，得到$$C_{1}(x) = - \int\frac{y_{2}(x)f(x)}{W(x)}dx + C_{1}$$，$$C_{2}(x) = \int\frac{y_{1}(x)f(x)}{W(x)}dx + C_{2}$$（$$C_{1},C_{2}$$为任意常数）。

得到通解：将$$C_{1}(x),C_{2}(x)$$代回$$y^{\ast}(x)$$，非齐次方程的通解为$$y = Y(x) + y^{\ast}(x) = C_{1}y_{1}(x) + C_{2}y_{2}(x) + y^{\ast}(x)$$。

**（四）求解示例（二阶非齐次线性方程）**

求解非齐次方程$$y^{''} - 3y^{\prime} + 2y = 2e^{x}$$（用常数变易法，与前文待定系数法对比），步骤如下：

求对应齐次方程通解：齐次方程$$y^{''} - 3y^{\prime} + 2y = 0$$，特征方程$$r^{2} - 3r + 2 = 0$$，根$$r_{1} = 1,r_{2} = 2$$，通解$$Y(x) = C_{1}e^{x} + C_{2}e^{2x}$$，其中$$y_{1}(x) = e^{x}$$，$$y_{2}(x) = e^{2x}$$。

计算朗斯基行列式：$$W(x) = \left| \begin{matrix}
e^{x} & e^{2x} \\
e^{x} & 2e^{2x}
\end{matrix} \right| = e^{x} \cdot 2e^{2x} - e^{x} \cdot e^{2x} = e^{3x}$$。

求解$$C_{1}^{\prime}(x),C_{2}^{\prime}(x)$$：已知$$f(x) = 2e^{x}$$，代入公式得：\
$$C_{1}^{\prime}(x) = - \frac{y_{2}(x)f(x)}{W(x)} = - \frac{e^{2x} \cdot 2e^{x}}{e^{3x}} = - 2$$$$C_{2}^{\prime}(x) = \frac{y_{1}(x)f(x)}{W(x)} = \frac{e^{x} \cdot 2e^{x}}{e^{3x}} = 2e^{- x}$$

积分求$$C_{1}(x),C_{2}(x)$$：\
$$C_{1}(x) = - \int 2dx + C_{1} = - 2x + C_{1}$$$$C_{2}(x) = \int 2e^{- x}dx + C_{2} = - 2e^{- x} + C_{2}$$

求特解与通解：特解$$y^{\ast}(x) = C_{1}(x)y_{1}(x) + C_{2}(x)y_{2}(x) = ( - 2x + C_{1})e^{x} + ( - 2e^{- x} + C_{2})e^{2x}$$，忽略含$$C_{1},C_{2}$$的项（对应齐次通解），得特解$$y^{\ast} = - 2xe^{x} - 2e^{x}$$（注：$$- 2e^{x}$$可纳入齐次通解，最终特解可简化为$$y^{\ast} = - 2xe^{x}$$，与待定系数法结果一致）；通解为$$y = C_{1}e^{x} + C_{2}e^{2x} - 2xe^{x}$$。

**（五）注意事项**

辅助条件的作用：求解非齐次方程时，引入辅助条件$$C_{1}^{\prime}(x)y_{1} + C_{2}^{\prime}(x)y_{2} = 0$$，是为了消去$$y^{\ast^{''}}$$中含$$C_{1}^{''}(x),C_{2}^{''}(x)$$的项，简化求解过程，不可省略。

常数的取舍：积分$$C_{1}(x),C_{2}(x)$$时，任意常数可保留，最终会与齐次通解的常数合并，不影响通解形式。

适用范围：常数变易法适用于所有二阶线性微分方程（变系数、常系数均可），尤其适用于变系数方程（无其他简便方法）；常系数方程可优先用特征方程法+待定系数法，更高效。

**四、n阶常系数齐次线性微分方程**

n阶常系数齐次线性微分方程是二阶常系数齐次线性微分方程的推广，求解思路与二阶一致，核心仍为"特征方程法"，无需积分，通过分析特征方程的根的类型，直接写出通解，具体解法如下：

**（一）n阶常系数齐次线性微分方程的定义与标准形式**

标准形式：$$y^{(n)} + a_{1}y^{(n - 1)} + a_{2}y^{(n - 2)} + \cdots + a_{n - 1}y^{\prime} + a_{n}y = 0$$，其中$$a_{1},a_{2},\ldots,a_{n}$$均为常数，$$y^{(k)}$$表示y的k阶导数（k=1,2,\...,n）。

关键说明：与二阶常系数齐次方程一致，核心特征是未知函数及其各阶导数均为一次项，系数为常数，求解核心是构造特征方程，根据特征根类型确定通解。

**（二）核心求解方法------特征方程法**

求解步骤与二阶方程完全一致，可分为3步，核心是将微分方程转化为代数方程（特征方程），通过求解代数方程的根，对应写出微分方程的通解。

构造特征方程：将标准形式中，$$y^{(k)}$$（k=0,1,\...,n，$$y^{(0)} = y$$）替换为$$r^{k}$$，得到n次代数方程，称为该微分方程的特征方程：$$r^{n} + a_{1}r^{n - 1} + a_{2}r^{n - 2} + \cdots + a_{n - 1}r + a_{n} = 0$$。

求解特征根：解上述n次特征方程，得到n个特征根（重根按重数计算，复根必成对出现，即若$$\alpha + i\beta$$是特征根，则$$\alpha - i\beta$$也必是特征根）。

根据特征根类型，写出对应通解：n阶常系数齐次线性微分方程的通解，是其n个线性无关特解的线性组合，不同类型的特征根，对应不同形式的特解，具体对应关系如下：

**（三）特征根类型及对应特解、通解形式**

结合二阶方程的特征根类型，推广至n阶，共4种核心类型，每种类型对应固定的特解形式，汇总如下：

**（四）求解示例（三阶常系数齐次线性微分方程）**

求解方程$$y^{'''} - 3y^{''} + 3y^{\prime} - y = 0$$，步骤如下：

构造特征方程：将$$y^{'''} \rightarrow r^{3}$$、$$y^{''} \rightarrow r^{2}$$、$$y^{\prime} \rightarrow r$$、$$y \rightarrow 1$$，得到特征方程：$$r^{3} - 3r^{2} + 3r - 1 = 0$$。

求解特征根：因式分解得$$(r - 1)^{3} = 0$$，即$$r = 1$$是3重实根（k=3）。

确定特解与通解：3重实根$$r = 1$$对应3个线性无关的特解：$$e^{x},xe^{x},x^{2}e^{x}$$，因此通解为：$$y = (C_{1} + C_{2}x + C_{3}x^{2})e^{x}$$（$$C_{1},C_{2},C_{3}$$为任意常数）。

**（五）补充示例（四阶常系数齐次线性微分方程）**

求解方程$$y^{⁗} - 2y^{''} + y = 0$$，步骤如下：

构造特征方程：$$r^{4} - 2r^{2} + 1 = 0$$，因式分解得$$(r^{2} - 1)^{2} = 0$$，进一步分解为$$(r - 1)^{2}(r + 1)^{2} = 0$$。

**（六）注意事项**

特征根的个数：n次特征方程必有n个根（重根按重数计算），因此微分方程必有n个线性无关的特解，通解必含n个任意常数。

复根的性质：共轭复根必成对出现，且重数相同，求解时无需保留复数形式，转化为实函数特解（$$e^{\alpha x}\cos\beta x$$、$$e^{\alpha x}\sin\beta x$$），避免复杂计算。

重根的特解：k重根对应k个线性无关的特解，核心是"乘以x的幂次"，从x⁰（即不乘x）到xᵏ⁻¹，不可漏写或多写幂次。

衔接二阶方程：二阶常系数齐次方程是n阶方程的特殊情况（n=2），其特征根类型（单实根、重实根、共轭复根）的通解形式，完全符合上述n阶方程的规律，可相互印证。

**五、注意事项**

特征方程法仅适用于**常系数**齐次线性微分方程，对于变系数齐次方程（系数为x的函数），需用其他方法求解（如欧拉方程）。

待定系数法求特解时，需准确匹配$$f(x)$$的类型，正确设出特解形式，尤其是k的取值（由特征根决定），避免设错形式导致求解错误。

通解的常数个数：n阶线性微分方程的通解，必含n个相互独立的任意常数，二阶方程通解含2个任意常数，不可遗漏。

线性无关的判断：两个解的比值为常数则线性相关，否则线性无关，这是齐次方程通解的核心条件。

推广说明：n阶常系数齐次线性微分方程，可通过构造n次特征方程，根据特征根的类型（实根、复根、重根），写出对应的通解，思路与二阶一致。

**二阶常系数线性微分方程的求解方法**

二阶常系数线性微分方程是高阶线性方程中最易求解、应用最广的类型，分为齐次和非齐次两种情况，重点掌握齐次方程通解、非齐次方程特解的求法。

**（一）二阶常系数齐次线性微分方程**$$y^{''} + py^{\prime} + qy = 0$$**的求解**

求解核心：通过"特征方程法"求解，无需积分，直接根据特征方程的根的类型，写出齐次方程的通解。

构造特征方程：将齐次方程中$$y^{''}$$换为$$r^{2}$$、$$y^{\prime}$$换为$$r$$、$$y$$换为1，得到特征方程：$$r^{2} + pr + q = 0$$（二次代数方程）。

求解特征根：解二次方程$$r^{2} + pr + q = 0$$，得到两个根$$r_{1},r_{2}$$，根据根的三种不同情况，对应齐次方程的三种通解形式：\
情况1：两个不相等的实根（$$\Delta = p^{2} - 4q > 0$$），$$r_{1} \neq r_{2}$$，通解为：$$y = C_{1}e^{r_{1}x} + C_{2}e^{r_{2}x}$$。

情况2：两个相等的实根（$$\Delta = p^{2} - 4q = 0$$），$$r_{1} = r_{2} = r$$，通解为：$$y = (C_{1} + C_{2}x)e^{rx}$$（补充一个线性无关解$$xe^{rx}$$）。

情况3：一对共轭复根（$$\Delta = p^{2} - 4q < 0$$），$$r_{1} = \alpha + i\beta$$，$$r_{2} = \alpha - i\beta$$（$$\alpha,\beta$$为实数，$$\beta \neq 0$$），通解为：$$y = e^{\alpha x}(C_{1}\cos\beta x + C_{2}\sin\beta x)$$。

示例1：求解齐次方程$$y^{''} - 3y^{\prime} + 2y = 0$$，步骤如下：

特征方程：$$r^{2} - 3r + 2 = 0$$。

求解特征根：因式分解得$$(r - 1)(r - 2) = 0$$，即$$r_{1} = 1$$，$$r_{2} = 2$$（不相等实根）。

通解：$$y = C_{1}e^{x} + C_{2}e^{2x}$$（$$C_{1},C_{2}$$为任意常数）。

示例2：求解齐次方程$$y^{''} - 2y^{\prime} + y = 0$$，步骤如下：

特征方程：$$r^{2} - 2r + 1 = 0$$。

求解特征根：$$(r - 1)^{2} = 0$$，即$$r_{1} = r_{2} = 1$$（相等实根）。

通解：$$y = (C_{1} + C_{2}x)e^{x}$$。

**（二）二阶常系数非齐次线性微分方程**$$y^{''} + py^{\prime} + qy = f(x)$$**的求解**

求解思路：先求对应齐次方程的通解$$Y(x)$$，再求非齐次方程的一个特解$$y^{\ast}(x)$$，最后通解为$$y = Y(x) + y^{\ast}(x)$$。核心难点是求特解$$y^{\ast}(x)$$，常用"待定系数法"，根据$$f(x)$$的形式设出特解形式，代入方程求解系数。

常见$$f(x)$$类型及特解设取（重点掌握2种）：

类型1：$$f(x) = P_{m}(x)e^{\lambda x}$$（$$P_{m}(x)$$是m次多项式，$$\lambda$$为常数）\
特解形式：$$y^{\ast} = x^{k}Q_{m}(x)e^{\lambda x}$$，其中$$Q_{m}(x)$$是与$$P_{m}(x)$$同次的待定多项式，k的取值由$$\lambda$$是否为特征根决定：\
k=0：$$\lambda$$不是特征方程的根；

k=1：$$\lambda$$是特征方程的单根；

k=2：$$\lambda$$是特征方程的二重根。

类型2：$$f(x) = e^{\alpha x}(A\cos\beta x + B\sin\beta x)$$（$$\alpha,\beta,A,B$$为常数，$$\beta \neq 0$$）\
特解形式：$$y^{\ast} = x^{k}e^{\alpha x}(C\cos\beta x + D\sin\beta x)$$，其中C、D为待定常数，k的取值由$$\alpha + i\beta$$是否为特征根决定：\
k=0：$$\alpha + i\beta$$不是特征根；

k=1：$$\alpha + i\beta$$是特征根。

示例：求解非齐次方程$$y^{''} - 3y^{\prime} + 2y = 2e^{x}$$，步骤如下：

求对应齐次方程通解$$Y(x)$$：\
齐次方程$$y^{''} - 3y^{\prime} + 2y = 0$$，特征方程$$r^{2} - 3r + 2 = 0$$，根$$r_{1} = 1$$，$$r_{2} = 2$$，通解$$Y(x) = C_{1}e^{x} + C_{2}e^{2x}$$。

求非齐次方程特解$$y^{\ast}(x)$$：\
$$f(x) = 2e^{x}$$，属于$$P_{0}(x)e^{\lambda x}$$（m=0，$$\lambda = 1$$）；$$\lambda = 1$$是特征方程的单根，故设$$y^{\ast} = x \cdot Q_{0}(x)e^{x} = Cxe^{x}$$（C为待定常数）。求导：$$y^{\ast^{\prime}} = C(e^{x} + xe^{x}) = C(1 + x)e^{x}$$，$$y^{\ast^{''}} = C(e^{x} + e^{x} + xe^{x}) = C(2 + x)e^{x}$$。代入原方程：$$C(2 + x)e^{x} - 3C(1 + x)e^{x} + 2Cxe^{x} = 2e^{x}$$，化简得$$- Ce^{x} = 2e^{x}$$，解得$$C = - 2$$，故$$y^{\ast} = - 2xe^{x}$$。

求非齐次方程通解：\
通解$$y = Y(x) + y^{\ast}(x) = C_{1}e^{x} + C_{2}e^{2x} - 2xe^{x}$$（$$C_{1},C_{2}$$为任意常数）。

**欧拉方程：**

欧拉方程是一类特殊的**变系数线性微分方程**，核心特征是方程中未知函数的各阶导数与自变量的幂次相乘，可通过变量代换转化为常系数线性微分方程求解，是连接变系数与常系数线性方程的重要桥梁，具体知识点如下：

**一、欧拉方程的定义与标准形式**

对于n阶线性微分方程，若其形式为：$$x^{n}y^{(n)} + a_{1}x^{n - 1}y^{(n - 1)} + a_{2}x^{n - 2}y^{(n - 2)} + \cdots + a_{n - 1}xy^{\prime} + a_{n}y = f(x)$$，则称该方程为n阶欧拉方程。

关键说明：

核心特征：方程中第k阶导数$$y^{(k)}$$（k=1,2,\...,n）始终与$$x^{k}$$相乘，系数$$a_{1},a_{2},\ldots,a_{n}$$均为常数（这是欧拉方程的核心标志，也是能转化为常系数方程的关键）。

适用范围：自变量x的取值范围通常为$$x > 0$$（若$$x < 0$$，可通过变量代换$$t = - x$$转化为$$t > 0$$的情况，求解方法一致）。

常见类型：工程和数学中最常用的是**二阶欧拉方程**，其标准形式为：$$x^{2}y^{''} + axy^{\prime} + by = f(x)$$（a、b为常数），后续重点讲解二阶欧拉方程的求解，n阶可类比推广。

与常系数方程的关联：欧拉方程本质是变系数方程，但通过特定变量代换（令$$x = e^{t}$$），可消去自变量的幂次，转化为常系数线性微分方程，再利用特征方程法等已学方法求解。

**二、欧拉方程的求解方法（以二阶为例，n阶可推广）**

求解核心思路：通过变量代换将变系数的欧拉方程，转化为常系数线性微分方程，具体步骤分为"变量代换→转化方程→求解方程→回代还原"四步，详细如下：

**（一）核心变量代换**

令$$x = e^{t}$$（即$$t = \ln x$$，因$$x > 0$$，t为实数），将自变量从x替换为t，同时将y对x的各阶导数，转化为y对t的各阶导数（核心是链式法则的应用）。

具体导数转化（二阶为例）：

一阶导数：由$$t = \ln x$$得$$\frac{dt}{dx} = \frac{1}{x}$$，根据链式法则：$$\frac{dy}{dx} = \frac{dy}{dt} \cdot \frac{dt}{dx} = \frac{1}{x} \cdot \frac{dy}{dt}$$，整理得$$x\frac{dy}{dx} = \frac{dy}{dt}$$（记为①式）。

二阶导数：对①式两边再对x求导，结合乘积法则和链式法则：\
$$\frac{d}{dx}\left( x\frac{dy}{dx} \right) = \frac{d}{dx}\left( \frac{dy}{dt} \right)$$左边：$$\frac{dy}{dx} + x\frac{d^{2}y}{dx^{2}}$$；右边：$$\frac{d^{2}y}{dt^{2}} \cdot \frac{dt}{dx} = \frac{1}{x} \cdot \frac{d^{2}y}{dt^{2}}$$整理得：$$x\frac{dy}{dx} + x^{2}\frac{d^{2}y}{dx^{2}} = \frac{d^{2}y}{dt^{2}}$$，代入①式（$$x\frac{dy}{dx} = \frac{dy}{dt}$$），最终得到：$$x^{2}\frac{d^{2}y}{dx^{2}} = \frac{d^{2}y}{dt^{2}} - \frac{dy}{dt}$$（记为②式）。

**（二）转化为常系数线性微分方程**

将①式、②式代入二阶欧拉方程的标准形式$$x^{2}y^{''} + axy^{\prime} + by = f(x)$$，替换后消去x的幂次，得到关于t和y的二阶常系数线性微分方程：

$$\frac{d^{2}y}{dt^{2}} - \frac{dy}{dt} + a \cdot \frac{dy}{dt} + by = f(e^{t})$$

化简后：$$\frac{d^{2}y}{dt^{2}} + (a - 1)\frac{dy}{dt} + by = f(e^{t})$$

该方程符合常系数线性微分方程的标准形式$$y^{''} + py^{\prime} + qy = F(t)$$（其中$$p = a - 1$$，$$q = b$$，$$F(t) = f(e^{t})$$），可利用前文所学的"特征方程法+待定系数法"求解。

**（三）求解转化后的常系数方程**

分两种情况求解，与二阶常系数线性方程的求解方法完全一致：

齐次欧拉方程（$$f(x) = 0$$）：此时转化后的方程为$$\frac{d^{2}y}{dt^{2}} + (a - 1)\frac{dy}{dt} + by = 0$$，构造特征方程$$r^{2} + (a - 1)r + b = 0$$，根据特征根类型（单实根、重实根、共轭复根），写出y关于t的通解$$y = \Phi(t)$$。

非齐次欧拉方程（$$f(x) \neq 0$$）：先求对应齐次方程的通解$$Y(t)$$，再根据$$F(t) = f(e^{t})$$的形式，用待定系数法求非齐次方程的一个特解$$y^{\ast}(t)$$，最终得到y关于t的通解$$y = Y(t) + y^{\ast}(t)$$。

**（四）回代还原，得到原方程的通解**

将变量代换$$t = \ln x$$（即$$x = e^{t}$$）代回y关于t的通解，替换后得到y关于x的函数，即为原欧拉方程的通解。若有初始条件，可代入通解求出任意常数，得到特解。

**三、求解示例（二阶欧拉方程，齐次+非齐次）**

**示例1：齐次欧拉方程求解**

求解方程$$x^{2}y^{''} - 2xy^{\prime} + 2y = 0$$（二阶齐次欧拉方程），步骤如下：

变量代换：令$$x = e^{t}$$（$$t = \ln x$$），根据前文导数转化公式：\
$$xy^{\prime} = \frac{dy}{dt}$$，$$x^{2}y^{''} = \frac{d^{2}y}{dt^{2}} - \frac{dy}{dt}$$。

转化方程：代入原方程，得：\
$$\left( \frac{d^{2}y}{dt^{2}} - \frac{dy}{dt} \right) - 2 \cdot \frac{dy}{dt} + 2y = 0$$化简：$$\frac{d^{2}y}{dt^{2}} - 3\frac{dy}{dt} + 2y = 0$$（常系数齐次线性方程）。

求解常系数方程：构造特征方程$$r^{2} - 3r + 2 = 0$$，解得$$r_{1} = 1$$，$$r_{2} = 2$$（不相等实根），通解为$$y = C_{1}e^{t} + C_{2}e^{2t}$$（$$C_{1},C_{2}$$为任意常数）。

回代还原：将$$t = \ln x$$代入，得$$e^{t} = x$$，$$e^{2t} = x^{2}$$，因此原方程的通解为：$$y = C_{1}x + C_{2}x^{2}$$。

**示例2：非齐次欧拉方程求解**

求解方程$$x^{2}y^{''} - xy^{\prime} + y = x\ln x$$（二阶非齐次欧拉方程），步骤如下：

变量代换：令$$x = e^{t}$$（$$t = \ln x$$），则$$x\ln x = e^{t} \cdot t$$，导数转化为：\
$$xy^{\prime} = \frac{dy}{dt}$$，$$x^{2}y^{''} = \frac{d^{2}y}{dt^{2}} - \frac{dy}{dt}$$。

转化方程：代入原方程，得：\
$$\left( \frac{d^{2}y}{dt^{2}} - \frac{dy}{dt} \right) - \frac{dy}{dt} + y = te^{t}$$化简：$$\frac{d^{2}y}{dt^{2}} - 2\frac{dy}{dt} + y = te^{t}$$（常系数非齐次线性方程）。

求解对应齐次方程：特征方程$$r^{2} - 2r + 1 = 0$$，解得$$r_{1} = r_{2} = 1$$（重实根），齐次通解$$Y(t) = (C_{1} + C_{2}t)e^{t}$$。

求非齐次特解$$y^{\ast}(t)$$：$$F(t) = te^{t}$$，属于$$P_{m}(t)e^{\lambda t}$$（m=1，$$\lambda = 1$$），$$\lambda = 1$$是二重特征根，故设特解为$$y^{\ast} = t^{2}(At + B)e^{t} = (At^{3} + Bt^{2})e^{t}$$（A、B为待定常数）。

求导代入求解：对$$y^{\ast}$$求一阶、二阶导数，代入化简后解得$$A = \frac{1}{6}$$，$$B = 0$$，故$$y^{\ast} = \frac{1}{6}t^{3}e^{t}$$。

回代还原：将$$t = \ln x$$代入，得原方程的通解：\
$$y = (C_{1} + C_{2}\ln x)x + \frac{1}{6}x(\ln x)^{3}$$（$$C_{1},C_{2}$$为任意常数）。

**四、n阶欧拉方程的推广（简要说明）**

对于n阶欧拉方程$$x^{n}y^{(n)} + a_{1}x^{n - 1}y^{(n - 1)} + \cdots + a_{n - 1}xy^{\prime} + a_{n}y = f(x)$$，求解思路与二阶一致：

变量代换：令$$x = e^{t}$$，引入算子$$D = \frac{d}{dt}$$（即$$Dy = \frac{dy}{dt}$$，$$D^{k}y = \frac{d^{k}y}{dt^{k}}$$），可证明$$x^{k}y^{(k)} = D(D - 1)(D - 2)\ldots(D - k + 1)y$$。

转化方程：将上述算子关系代入n阶欧拉方程，转化为关于t的n阶常系数线性微分方程。

求解回代：求解常系数方程，再将$$t = \ln x$$回代，得到原n阶欧拉方程的通解。

**五、注意事项**

变量代换的适用条件：默认$$x > 0$$，若题目中x的取值范围包含$$x < 0$$，可令$$t = \ln( - x)$$，导数转化关系不变，求解方法完全一致。

导数转化的准确性：二阶欧拉方程的导数转化（$$xy^{\prime} = \frac{dy}{dt}$$、$$x^{2}y^{''} = \frac{d^{2}y}{dt^{2}} - \frac{dy}{dt}$$）是核心，需牢记链式法则的应用，避免计算错误。

特解的设取：非齐次欧拉方程转化后，$$F(t) = f(e^{t})$$，需根据$$F(t)$$的形式设取特解，与常系数非齐次方程的特解设取规则完全一致，重点关注$$\lambda$$是否为特征根。

与常系数方程的区别：欧拉方程是变系数方程，不可直接用特征方程法求解，必须先通过变量代换转化为常系数方程，这是欧拉方程求解的关键步骤，不可省略。

特殊解验证：若求解过程中出现"除以x"的操作，需验证$$x = 0$$是否为原方程的解（通常$$x = 0$$不满足欧拉方程，无需纳入通解）。
