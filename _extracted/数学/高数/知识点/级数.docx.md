**级数**

**含对数因子的** $$p$$**-级数敛散性**

**一、级数基本形式**

$$\sum_{n = 2}^{\infty}{}\frac{1}{n^{m} \cdot (\ln n)^{a}}$$

**起点说明**：$$n$$ 从 2 开始，避免 $$\ln 1 = 0$$ 导致分母为 0，若题目中级数起点为 $$n = 1$$，需忽略 $$n = 1$$ 项（单一项不影响敛散性），从 $$n = 2$$ 开始判断。

**参数定义**：$$m,a$$ 为任意实常数，是敛散性判断的核心变量；$$m$$ 对应标准 $$p$$-级数的幂次（类比 $$\sum_{n = 1}^{\infty}{}\frac{1}{n^{p}}$$ 中的 $$p$$），$$a$$ 为对数因子的幂次。

**二、核心判别方法：积分判别法**

适用条件

函数 $$f(x) = \frac{1}{x^{m}(\ln x)^{a}}$$ 在 $$\lbrack 2, + \infty)$$ 上满足：

非负：$$x \geq 2$$ 时，$$x^{m} > 0$$、$$\ln x > 0$$，故 $$f(x) > 0$$，天然满足；

连续：分母无零点、无间断点，函数连续；

单调递减：可通过求导验证 $$f^{\prime}(x) < 0$$，无需死记求导过程，记住该形式函数在 $$\lbrack 2, + \infty)$$ 单调递减即可。

结论：级数 $$\sum_{n = 2}^{\infty}{}f(n)$$ 与反常积分 $$\int_{2}^{+ \infty}{}\frac{1}{x^{m}(\ln x)^{a}}dx$$**同敛散**（积分收敛→级数收敛，积分发散→级数发散）。

**三、敛散性分情况讨论（核心重点）**

**1. 当** $$m > 1$$ **时**

主导项分析：主导项为 $$\frac{1}{n^{m}}$$，对应标准 $$p$$-级数（$$p = m > 1$$），本身收敛；

对数因子影响：$$\ln n$$ 增长远慢于任何正幂函数，无论 $$a$$ 取何实数值，$$(\ln n)^{a}$$ 都无法改变级数的收敛性；

**结论**：级数收敛

**2. 当** $$m < 1$$ **时**

主导项分析：主导项为 $$\frac{1}{n^{m}}$$，对应标准 $$p$$-级数（$$p = m < 1$$），本身发散；

对数因子影响：$$(\ln n)^{a}$$ 无法抵消幂函数的发散趋势，无论 $$a$$ 取何实数值，都不能改变级数的发散性；

**结论**：级数发散

**3. 当** $$m = 1$$ **时（关键分界点）**

级数简化为：$$\sum_{n = 2}^{\infty}{}\frac{1}{n(\ln n)^{a}}$$

变量替换求积分：令 $$t = \ln x$$，则 $$dt = \frac{1}{x}dx$$，反常积分变为：

$$\int_{2}^{+ \infty}{}\frac{1}{x(\ln x)^{a}}dx = \int_{\ln 2}^{+ \infty}{}\frac{1}{t^{a}}dt$$

若 $$a > 1$$：积分 $$\int_{\ln 2}^{+ \infty}{}\frac{1}{t^{a}}dt$$ 收敛（$$p$$-积分 $$p = a > 1$$）→ 级数收敛 ；

若 $$a \leq 1$$：积分发散 → 级数发散 。

**四、结论速查表（方便快速检索）**

  ----------------------- ----------------------- -----------------------
  $$m$$ 取值              $$a$$取值               敛散性

  $$m > 1$$               任意实数                **收敛**

  $$m < 1$$               任意实数                **发散**

  $$m = 1$$               $$a > 1$$               **收敛**

  $$m = 1$$               $$a \leq 1$$            **发散**
  ----------------------- ----------------------- -----------------------

**五、典型例题（巩固记忆，贴合真题难度）**

$$\sum_{n = 2}^{\infty}{}\frac{1}{n^{2}(\ln n)^{5}}$$：$$m = 2 > 1$$ → 收敛；

$$\sum_{n = 2}^{\infty}{}\frac{1}{\sqrt{n}\ln n}$$：$$m = \frac{1}{2} < 1$$ → 发散；

$$\sum_{n = 2}^{\infty}{}\frac{1}{n(\ln n)^{3}}$$：$$m = 1,a = 3 > 1$$ → 收敛；

$$\sum_{n = 2}^{\infty}{}\frac{1}{n\ln n}$$：$$m = 1,a = 1$$ → 发散；

$$\sum_{n = 2}^{\infty}{}\frac{1}{n(\ln n)^{0.5}}$$：$$m = 1,a = 0.5 < 1$$ → 发散。

**六、记忆技巧（避免混淆，快速解题）**

先看 $$m$$：$$m > 1$$ 必收敛，$$m < 1$$ 必发散，无需考虑 $$a$$（$$m$$ 是主导因素）；

再看 $$a$$：仅当 $$m = 1$$ 时，才需判断 $$a$$，规律同 $$p$$-积分（$$a > 1$$ 收敛，$$a \leq 1$$ 发散）；

本质理解：幂函数 $$n^{m}$$ 增长速度远快于对数函数 $$\ln n$$，因此 $$m$$ 决定敛散大方向，$$a$$ 仅在分界点 $$m = 1$$ 时起作用。
