## 不定积分（二）

公式:

万能代换（三角函数专用）：令 $t=\tan\frac{x}{2}$ （即 $x=2\arctan t$ ），则 $dx=\frac{2}{1+t^{2}}dt$ ，且核心三角函数转化公式为： $\sin x=\frac{2t}{1+t^{2}}$ ， $\cos x=\frac{1-t^{2}}{1+t^{2}}$ 。

习题：

习题 22：求积分 $\int\frac{1+x^{2}}{1+x^{4}}dx$

关键步骤：

1. 分子分母同除以 $x^{2}$ ，原式化为 $\int \frac{\frac{1}{x^2} + 1}{x^2 + \frac{1}{x^2}} dx$ ;

2. 变形分母： $x^{2}+\frac{1}{x^{2}}=(x-\frac{1}{x})^{2}+2$ ，令 $t=x-\frac{1}{x}$ ，则 $dt=(1+\frac{1}{x^{2}})dx$ ;

3. 换元后积分： $\int \frac{dt}{t^2 + 2} = \frac{1}{\sqrt{2}}\arctan \left(\frac{t}{\sqrt{2}}\right) + C;$

4. 回代得结果： $\frac{1}{\sqrt{2}}\arctan \left(\frac{x - \frac{1}{x}}{\sqrt{2}}\right) + C$ （可整理为 $\frac{1}{\sqrt{2}}\arctan \left(\frac{x^2 - 1}{\sqrt{2}x}\right) + C$ ）。

习题 23: 求积分 $\int \frac{\ln(\sin x)}{\sin^{2}x} dx$

关键步骤：

1. 采用分部积分法，令 $u = \ln (\sin x)$ ， $dv = \frac{1}{\sin^2 x} dx$ ;

2. 计算 $du = \frac{\cos x}{\sin x} dx = \cot x dx, v = -\cot x;$

3. 分部积分公式： $\int u dv = uv - \int v du$ ，代入得 $-\cot x \cdot \ln (\sin x) + \int \cot^2 x dx$ ;

4. 化简积分： $\int\cot^{2}xdx=\int(csc^{2}x-1)dx=-\cot x-x+C;$

5. 整理得结果： $-\cot x \cdot \ln (\sin x) - \cot x - x + C$ 。

## 有关递推：

1. 求递推公式 $I_{n} = \int \sin^{n} x dx$

关键步骤：

1. 分部积分：令 $u = \sin^{n - 1}x$ ， $dv = \sin xdx$

2. 得 $du=(n-1)\sin^{n-2}x\cos xdx$ ， $v=-\cos x;$

3. 代入公式： $I_{n}=-\sin^{n-1}x\cos x+(n-1)\int\sin^{n-2}x\cos^{2}xdx;$

4. 化简： $\cos^2 x = 1 - \sin^2 x$ ，得递推式 $I_n = -\frac{1}{n} \sin^{n-1} x \cos x + \frac{n-1}{n} I_{n-2} (n \geq 2)$ 。

2. 求递推公式 $I_{n}=\int\cos^{n}x dx$

关键步骤：

1. 分部积分：令 $u = \cos^{n-1} x$ ， $dv = \cos x dx$ ；

2. 得 $du = -(n - 1)\cos^{n - 2}x\sin xdx, v = \sin x;$

3. 代入公式： $I_{n}=\cos^{n-1}x\sin x+(n-1)\int\cos^{n-2}x\sin^{2}xdx;$

4. 化简： $\sin^{2}x=1-\cos^{2}x$ ，得递推式 $I_{n}=\frac{1}{n}\cos^{n-1}x\sin x+\frac{n-1}{n}I_{n-2}(n\geq2)$ 。

3. 求递推公式 $I_{n}=\int\tan^{n}x dx$

关键步骤：

1. 变形： $\tan^{n}x=\tan^{n-2}x\left(sec^{2}x-1\right)=\tan^{n-2}xsec^{2}x-\tan^{n-2}x;$

2. 拆分积分： $I_{n}=\int\tan^{n-2}x\sec^{2}xdx-\int\tan^{n-2}xdx=\int\tan^{n-2}xd(\tan x)-I_{n-2};$

3. 积分得递推式： $I_{n}=\frac{1}{n-1}\tan^{n-1}x-I_{n-2}(n\geq2)$ 。

4. 求递推公式 $I_{n} = \int \csc^{n} x \, dx$

关键步骤：

1. 分部积分：令 $u = \csc^{n - 2}x$ ， $dv = \csc^2 xdx$

2. 得 $du = -\left(n - 2\right)csc^{n - 2}x \cot x dx, v = -\cot x;$

3. 代入公式： $I_{n}=-csc^{n-2}x\cot x-(n-2)\int csc^{n-2}x\cot^{2}xdx;$

4. 化简： $\cot^2 x = \csc^2 x - 1$ ，得递推式 $I_n = -\frac{1}{n-1} \csc^{n-2} x \cot x + \frac{n-2}{n-1} I_{n-2} (n \geq 2)$ 。

5. 求递推公式 $I_{n} = \int sec^{n} x dx$

## 关键步骤：

1. 分部积分：令 $u = sec^{n - 2}x$ ， $dv = sec^2 x dx$ ；

2. 得 $du=(n-2)\sec^{n-2}x\tan xdx,\quad v=\tan x;$

3. 代入公式： $I_{n}=sec^{n-2}x\tan x-(n-2)\int sec^{n-2}x\tan^{2}xdx;$

4. 化简： $\tan^2 x = \sec^2 x - 1$ ，得递推式 $I_n = \frac{1}{n-1} \sec^{n-2} x \tan x + \frac{n-2}{n-1} I_{n-2} (n \geq 2)$ 。

6. 求递推公式 $I_{n} = \int \frac{1}{x^{n}\sqrt{1 + x^{2}}} dx$

关键步骤：

1. 换元法：令 $x = \tan t$ （ $t \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ ），则 $dx = sec^2 t dt$ ，且 $\sqrt{1 + x^2} = sec t$ ；

2. 代入化简： $I_{n}=\int\frac{1}{\tan^{n}t\cdot sec t}\cdot sec^{2}tdt=\int\frac{sec t}{\tan^{n}t}dt=\int\frac{\cos^{n-1}t}{\sin^{n}t}dt;$

3. 分部积分（换元后衔接）：令 $u = \cos^{n-2} t$ ， $dv = \frac{\cos t}{\sin^n t} dt$ ，则 $du = -(n-2)\cos^{n-3} t \sin t dt$ ， $v = \frac{-1}{(n-1)\sin^{n-1} t}$ ；
