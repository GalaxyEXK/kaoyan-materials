**定积分与反常积分**

**概念：**

**1.积分近似求和公式（定积分定义应用）：**

概念：若函数$$f(x)$$在区间$$\lbrack a,b\rbrack$$上连续，将$$\lbrack a,b\rbrack$$等分$$n$$份，每份区间长度$$\Delta x = \frac{b - a}{n}$$，取区间内任意一点$$\xi_{i}$$（常用$$\xi_{i} = a + i\Delta x$$），则$$\int_{a}^{b}{}f(x)dx = \lim_{n \rightarrow \infty}\sum_{i = 1}^{n}{}f(\xi_{i})\Delta x$$；当$$a = 0,b = 1$$时，简化为$$\int_{0}^{1}{}f(x)dx = \lim_{n \rightarrow \infty}\frac{1}{n}\sum_{i = 1}^{n}{}f\left( \frac{i}{n} \right)$$。

用法：适用于$$n \rightarrow \infty$$的求和极限，核心是将求和式变形为"$$\sum f(\xi_{i})\Delta x$$"形式，关键步骤：① 提取$$\frac{1}{n}$$（即$$\Delta x$$）；② 将求和式中的变量整理为$$\frac{i}{n}$$（即$$\xi_{i}$$）；③ 对应转化为定积分计算；对于$$\sum_{k = 1}^{n}{}f(k)$$（无$$\frac{1}{n}$$），可通过提取$$n^{k}$$转化为定积分近似，或直接用$$\sum_{k = 1}^{n}{}f(k) \sim \int_{0}^{n}{}f(x)dx$$（$$n \rightarrow \infty$$）近似。

设$$F(x)$$为$$f(x)$$的一个原函数，且当$$x \geq 0$$时$$f(x)F(x) = \frac{xe^{x}}{2(1 + x)^{2}}$$，已知$$F(0) = 1$$且$$F(x) > 0$$，求$$F(x)$$。

关键步骤：1. 由原函数定义，$$F^{\prime}(x) = f(x)$$，代入已知式得$$F(x)F^{\prime}(x) = \frac{xe^{x}}{2(1 + x)^{2}}$$；2. 两边积分：$$\int F(x)F^{\prime}(x)dx = \int\frac{xe^{x}}{2(1 + x)^{2}}dx$$，左边得$$\frac{1}{2}F^{2}(x)$$；3. 右边用分部积分，令$$u = e^{x}$$，$$dv = \frac{x}{2(1 + x)^{2}}dx$$，计算得$$\frac{e^{x}}{2(1 + x)} + C$$；4. 代入$$F(0) = 1$$求$$C = 0$$，结合$$F(x) > 0$$，得$$F(x) = \sqrt{\frac{e^{x}}{1 + x}}$$。
