# 多元函数微分学.docx

**多元函数微分学**

**题目：**

**题1：**

$$若对任意t > 0有f(tx,ty) = t^{n}f(x,y)，则称函数f(x,y)是n次齐次函数。$$

$$试证：若f(x,y)可微，则f(x,y)是n次齐次函数 \Longleftrightarrow x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y} = nf(x,y)$$

证明过程

必要性（\\(\\Rightarrow\\)）

已知 \\( f(x,y) \\) 是 \\( n \\) 次齐次函数，即对任意 \\( t\>0 \\)，有：

$$f(tx,ty) = t^{n}f(x,y)$$

将上式两边对 \\( t \\) 求导（利用链式法则）：

$$xf_{1}^{\prime}(tx,ty) + yf_{2}^{\prime}(tx,ty) = nt^{n - 1}f(x,y)$$

令 \\( t=1 \\)，代入得：

$$xf_{x}^{\prime}(x,y) + yf_{y}^{\prime}(x,y) = nf(x,y)$$

即：

$$x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y} = nf(x,y)$$

\-\--

充分性（\\(\\Leftarrow\\)）

$$令F(t) = f(tx,ty)（t > 0），对t求导：$$

$$\frac{dF}{dt} = xf_{1}^{\prime}(tx,ty) + yf_{2}^{\prime}(tx,ty)$$

$$两边同乘t：$$

$$t\frac{dF}{dt} = txf_{1}^{\prime}(tx,ty) + tyf_{2}^{\prime}(tx,ty)$$

$$x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y} = nf(x,y)$$

$$txf_{1}^{\prime}(tx,ty) + tyf_{2}^{\prime}(tx,ty) = nf(tx,ty) = nF(t)$$

因此得到微分方程：

$$t\frac{dF}{dt} = nF(t) \Longrightarrow \frac{dF}{F} = \frac{n}{t}dt$$

积分得：

$$\ln|F(t)| = n\ln t + C \Longrightarrow F(t) = Ct^{n}$$

$$令t = 1，则F(1) = f(x,y) = C \cdot 1^{n} \Longrightarrow C = f(x,y)。$$

$$故：$$

$$F(t) = t^{n}f(x,y) \Longrightarrow f(tx,ty) = t^{n}f(x,y)$$

$$即f(x,y)是n次齐次函数。$$

结论:

$$若f(x,y)可微，则f(x,y)为n次齐次函数的充要条件是x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y} = nf(x,y)$$
