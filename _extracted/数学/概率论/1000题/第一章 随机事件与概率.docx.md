这就是数学里的组合问题，记作 $C_{5}^{2}$ （也写作 $\binom{5}{2}$ ）。

5. 设 $A, B$ 为随机事件， $0 < P(A) < 1, 0 < P(B) < 1$ ，且 $P(A - B) = 0$ ，则（ ）.
(A) $\overline{A} \supset \overline{B}$ (B) $P(\overline{A}) < P(\overline{B})$ (C) $P(\overline{B} \mid \overline{A}) = 0$ (D) $P(\overline{A} \mid \overline{B}) = 1$

## 二、核心区别：概率为 $0 \neq$ 集合为空

题目条件是 $P(A - B) = 0$ ，也就是 $P(A\bar{B}) = 0$ 。

它只说明：“A 发生、B 不发生”这个区域的概率是 0，但不代表这个区域里一个样本点都没有。

而 A 选项要求的是：“A 发生、B 不发生”这个区域里，连一个样本点都不能有（也就是 $A\bar{B} = \varnothing$ ，即严格的 $A \subset B$ ）。

只要这个区域里存在哪怕1个样本点（哪怕它概率为0），A选项的集合包含关系就不成立。

## 三、举一个具体的反例（一看就懂）

我们用连续区间的例子，完全符合题目条件，但A选项不成立：

\- 样本空间：在区间 $[0,1]$ 上随机取一个数，概率 $=$ 区间长度

\- 设事件 $A = [0, 0.5]$ （取到的数 $\leq 0.5$ ）

\- 设事件 $B = [0, 0.5)$ （取到的数 $< 0.5$ ）

## 第一步：验证满足题目条件

$A - B = A\bar{B} = \{0.5\}$ （只有“取到 $0.5^{\prime \prime}$ 这一个点）

单点的长度为0，因此 $P(A - B) = 0$ ，完全符合题目的条件。

第二步：看A选项是否成立

\- $\bar{B}$ (B 不发生): [0.5, 1] (包含 0.5 这个点)

\- $\bar{A}$ (A 不发生): (0.5, 1] (不包含 0.5 这个点)

很明显：

0.5 这个点属于 $\bar{B}$ ，但不属于 $\bar{A}$ 。

也就是说， $\bar{B}$ 不是 $\bar{A}$ 的子集， $\bar{A} \supset \bar{B}$ 不成立。

这就证明了：只给 $P(A - B) = 0$ ，推不出A选项的集合包含关系。

## 第一步：把题设彻底展开

这道题不要凭感觉判断。看到

$$
P (B \cup C \mid A) = P (B \mid A) + P (C \mid A)
$$

马上想到概率加法公式：

$$
P (B \cup C \mid A) = P (B \mid A) + P (C \mid A) - P (B C \mid A).
$$

而题目告诉我们：

$$
P (B \cup C \mid A) = P (B \mid A) + P (C \mid A).
$$

两式对比，立刻得到：

$$
\boxed {P (B C \mid A) = 0.}
$$

由于 $P(A) > 0$

$$
P (B C \mid A) = \frac {P (A B C)}{P (A)} = 0,
$$

因此

$$
\boxed {P (A B C) = 0.}
$$

这就是整道题唯一真正得到的信息。

② $P(B+C)=P(B|A)+P(C|A)$

左边是无条件概率（一个0到1的数），右边是两个条件概率之和（可以大于1），量纲和意义都不对。随便举个反例： $P(A)$ 很小时， $P(B|A)+P(C|A)$ 可以远大于 $P(B+C)$ 。②错误。
