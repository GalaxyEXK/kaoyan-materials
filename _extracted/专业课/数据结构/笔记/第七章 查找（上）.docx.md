判定树是一种用于描述查找过程的二叉树，在数据结构中主要用来分析二分查找（折半查找）的性能。

树的叶子节点代表查找不成功的情况（区间为空，未找到目标）

树的深度决定了查找的最大比较次数，平均深度对应平均查找长度（ASL）判定树是一棵平衡二叉树（或接近平衡），树的高度 $h = \lfloor \log 2n \rfloor + 1$ 。

二分查找的最多比较次数 = 判定树的高度 h。

二分查找的平均查找长度 $\approx$ 树的平均深度，约为 $\log 2(n + 1) - 1$ 。

判定树的形态只与表长 n 有关，与表中元素的具体值无关。判定树是静态的，描述固定表长的查找过程，不涉及插入 / 删除。

判定树的各分支高度最多相差一

判定树是一棵平衡二叉树

## 分块查找：

将长度为 n 的查找表均匀地分为 b 块，每块有 s 个计录，在等概率情况下，若在块内和索引表中均采用顺序查找，则 ASL=(b+1)/2 + (s+1)/2

若 $s=\sqrt{n}$ ，则ASL取最小值 $\sqrt{n}+1$

## 知识点：

1. 一般线性表的顺序查找和有序线性表的顺序查找在成功时的 ASL 都为 $(n+1)/2$

一般线性表的顺序查找失败时的 ASL 为 $(n+1)$ ，有序线性表的顺序查找失败时为 $\frac{n}{2} + \frac{n}{n+1}$

2. 有序线性表的顺序查找中的线性表可以是链式存储结构，但折半查找中的线性表只能是顺序存储结构。

原因：折半查找需要频繁、快速地定位中间元素，只有支持随机存取的顺序结构才能做到，链表做不到。

顺序查找 = 挨个遍历，不跳位置、不直接访问中间元素，所以：数组可以从头遍历，链表也可以从头遍历。

3. 折半查找成功的 ASL= $\frac{n+1}{n}\log_{2}(n+1)-1$ ，其中 h=log2(n+1)

卡特兰数（Catalan Number）是组合数学中一个非常重要的数列，在数据结构与算法中主要用于解决各类带约束的计数问题（如合法出栈序列、括号匹配、二叉树结构数等）。

## 一、定义与公式

设第 $n$ 项卡特兰数为 $C_n$ ( $n \geq 0$ )。

1. 通项公式

$$
C _ {n} = \frac {1}{n + 1} \binom {2 n} {n} = \frac {(2 n) !}{(n + 1) !   n !}
$$

2. 递推公式

\- 递归式（常用）：

$$
C _ {0} = 1, \quad C _ {n + 1} = \sum_ {i = 0} ^ {n} C _ {i} \cdot C _ {n - i} \quad (n \geq 0)
$$

\- 递推式（高效）：

$$
C _ {n} = \frac {4 n - 2}{n + 1} \cdot C _ {n - 1}
$$

3. 前几项值

$$
C _ {0} = 1, C _ {1} = 1, C _ {2} = 2, C _ {3} = 5, C _ {4} = 1 4, C _ {5} = 4 2, C _ {6} = 1 3 2, C _ {7} = 4 2 9 \dots

## 红黑树：

## 红黑树的性质：

红黑树是一种自平衡的二叉查找树，通过给节点染色 + 旋转，保证树的高度始终为 $O(\log n)$ ，从而保证插入、删除、查找的时间复杂度都是 $O(\log n)$ 。

## 一、红黑树的5条核心性质（必须背熟）

所有性质都是对任意节点成立的全局约束，缺一不可。

1. 节点颜色性质：每个节点要么是红色，要么是黑色。

2. 根节点性质：根节点是黑色。

3. 叶子节点性质：所有的叶子节点（NIL 节点，空节点）都是黑色。

注意：这里的叶子节点指的是虚拟的空哨兵节点，不是存储数据的终端节点，这是红黑树的特殊定义。

4. 红色节点性质：如果一个节点是红色，那么它的两个子节点都是黑色（即不存在两个连续的红色节点）。

5. 黑高性质：从任意一个节点出发，到其所有后代叶子节点（NIL 节点）的路径上，包含相同数量的黑色节点（这个数量称为该节点的黑高，记为 $bh(x)$ ）。

在数据结构（特别是树结构）中，分支结点（也叫非叶子结点、内部结点）的定义需要明确几点：

## 1. 分支结点是什么？

分支结点是指度（孩子数）大于 0 的结点。简单说，就是至少有一个孩子的结点。

## 2. 分支结点是否包含根节点和叶子结点？

\- 根节点：如果树非空，根节点可能是分支结点，也可能是叶子结点。

例如：树只有一个根节点（无孩子）→此时根节点是叶子，不是分支结点。

\- 如果根节点有至少一个孩子 $\rightarrow$ 根节点是分支结点。

\- 所以结论：根节点可以是分支结点，但不一定是。一般教材里“分支结点”通常泛指非叶子结点，因此包含有孩子的根，但不包含无孩子的根。

\- 叶子结点：叶子结点的度为 0，所以叶子结点不是分支结点。

\- 因此：分支结点不包含任何叶子结点，但可能包含（有孩子的）根节点。

## 3. 常见教材默认语境：

在多数数据结构的树与二叉树章节中，如果说“分支结点”，通常默认排除叶子结点，而是否包含根节点要看树的结构：

对于非空树且根有孩子 → 根属于分支结点。

对于空树或只有根节点 → 没有分支结点。
