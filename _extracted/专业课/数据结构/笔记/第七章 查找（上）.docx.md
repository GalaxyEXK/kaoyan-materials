判定树是一种用于描述查找过程的二叉树，在数据结构中主要用来分析二分查找（折半查找）的性能。

树的叶子节点代表查找不成功的情况（区间为空，未找到目标）

树的深度决定了查找的最大比较次数，平均深度对应平均查找长度（ASL）判定树是一棵平衡二叉树（或接近平衡），树的高度 h=⌊log2n⌋+1。

二分查找的最多比较次数 = 判定树的高度 h。

二分查找的平均查找长度 ≈ 树的平均深度，约为 log2(n+1)−1。

判定树的形态只与表长 n 有关，与表中元素的具体值无关。判定树是静态的，描述固定表长的查找过程，不涉及插入 / 删除。

判定树的各分支高度最多相差一

判定树是一棵平衡二叉树

**分块查找：**

将长度为n的查找表均匀地分为b块，每块有s个计录，在等概率情况下，若在块内和索引表中均采用顺序查找，则ASL=(b+1)/2 + ( s+1)/2

若$$s = \sqrt{n}$$,则ASL取最小值$$\sqrt{n} + 1$$

**知识点：**

1.一般线性表的顺序查找和有序线性表的顺序查找在成功时的ASL都为（n+1）/2

一般线性表的顺序查找失败时的ASL为$$(n + 1)$$,有序线性表的顺序查找失败时为$$\frac{n}{2} + \frac{n}{n + 1}$$

2.有序线性表的顺序查找中的线性表可以是链式存储结构，但折半查找中的线性表只能是顺序存储结构。

原因：折半查找需要频繁、快速地定位中间元素，只有支持随机存取的顺序结构才能做到，链表做不到。

顺序查找 = 挨个遍历，不跳位置、不直接访问中间元素，所以：数组可以从头遍历，链表也可以从头遍历。

3.折半查找成功的ASL=$$\frac{n + 1}{n}\log_{2}(n + 1) - 1$$，其中h=log2(n+1)

**二叉排序树的删除：**

  -----------------------------------------------------------------------
  C++\
  // 二叉排序树删除结点：递归实现\
  // 输入：根结点T，要删除的关键字key\
  // 输出：删除后的根结点（根可能变化，必须返回新根）\
  BSTNode\* BST_Delete(BiTree T, KeyType key) {\
  if (T == NULL) return NULL; // 空树，删除失败，返回NULL\
  \
  // 1. 查找要删除的结点\
  if (key \< T-\>data) {\
  // 目标在左子树，递归删除左子树，更新左孩子指针\
  T-\>lchild = BST_Delete(T-\>lchild, key);\
  } else if (key \> T-\>data) {\
  // 目标在右子树，递归删除右子树，更新右孩子指针\
  T-\>rchild = BST_Delete(T-\>rchild, key);\
  } else {\
  // 2. 找到目标结点T，分3种情况处理\
  BSTNode \*temp;\
  // 情况1：只有右子树（或叶子结点，右子树为NULL）\
  if (T-\>lchild == NULL) {\
  temp = T;\
  T = T-\>rchild; // 用右子树替代当前结点\
  free(temp); // 释放原结点\
  }\
  // 情况2：只有左子树\
  else if (T-\>rchild == NULL) {\
  temp = T;\
  T = T-\>lchild; // 用左子树替代当前结点\
  free(temp); // 释放原结点\
  }\
  // 情况3：左右子树都存在 → 用直接后继（右子树最左结点）替代\
  else {\
  // 找右子树的最左结点（直接后继，比当前结点大的最小结点）\
  temp = T-\>rchild;\
  while (temp-\>lchild != NULL) {\
  temp = temp-\>lchild;\
  }\
  // 用后继结点的值覆盖当前结点\
  T-\>data = temp-\>data;\
  // 递归删除右子树中的后继结点（此时后继结点最多只有右子树）\
  T-\>rchild = BST_Delete(T-\>rchild, temp-\>data);\
  }\
  }\
  return T; // 返回更新后的根结点\
  }

**知识点：**

1.对二叉排序树进行中序遍历可以得到一个递增的有序序列。

2.二分查找的判定树唯一，而二叉排序树的查找不唯一。

3.二叉排序树的插入和删除操作的平均执行时间是O(log2n)

4.二分查找的对象是有序顺序表，若有插入和删除结点的操作，所花的代价是O(n)

5.当有序表是静态查找表时，宜用顺序表作为其存储结构，而采用二分查找实现其查找操作；

当有序表是动态查找表时，应选择二叉排序树作为其逻辑结构。

6.二叉排序树的查找效率主要取决于树的高度
