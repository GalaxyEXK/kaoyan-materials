**顺序表的定义：**

顺序表是用一段连续的内存空间（数组）存储数据元素，元素的逻辑顺序和物理存储顺序完全一致。

  return -1;\

  return 0;\

  printf(\"扩容失败！\\n\");\
  return -1;\

  list-\>capacity = list-\>capacity \* 2; // 更新容量\
  printf(\"顺序表扩容成功，新容量：%d\\n\", list-\>capacity);\
  return 0;\
  }\

  if (list-\>data != NULL) {\
  free(list-\>data); // 释放堆内存\
  list-\>data = NULL; // 避免野指针\
  list-\>length = 0;\
  list-\>capacity = 0;\
  }\

**概念：**

**随机存取：**

随机存取（Random Access）是指可以直接访问数据结构中的任意一个元素，且访问所需的时间与元素的位置无关（通常为 O(1) 时间复杂度）。

换句话说，只要知道元素的序号（索引），就能立即定位到它，而不需要从头开始逐个查找。

典型结构：顺序表、一维数组。

**顺序存取：**

顺序存取是指访问数据元素时，必须从第一个元素开始，按逻辑次序依次访问，才能找到目标元素。访问时间与元素的位置有关，平均时间复杂度为 O(n)。

换句话说，要访问第 i 个元素，必须先访问前 i-1 个元素，不能直接跳转。

典型结构：单链表、双链表。

**散列存取：**

散列存取是指通过散列函数（哈希函数），将元素的关键字直接计算出存储地址，从而直接访问元素。理想情况下，访问时间与元素个数、位置均无关，平均时间复杂度为 O(1)。

典型结构：哈希表（散列表）。

**索引存取：**

索引存取是指先通过一个索引表找到目标元素的实际存储地址，再根据地址访问元素。索引表中记录了关键字与元素位置的对应关系，先查索引、再取数据。访问效率取决于索引查找方式，通常比直接顺序查找更快。

典型结构：索引顺序表、数据库索引、文件索引结构。

**存储密度：**

存储密度是指数据本身占用的存储空间与节点总共占用的存储空间之比。简单来说，就是存储结构中有多大比例的空间是真正用来存数据的，而不是存辅助信息（如指针）的。

**线性表的链式表示：**

链表是用一组不连续的内存节点存储数据元素，每个节点包含 "数据域" 和 "指针域（游标）"，通过指针将节点串联成逻辑上的连续序列。

**插入操作：**

  -----------------------------------------------------------------------
  C++\
  /\*\*\
  \* 在节点p后插入新节点s（双链表核心插入操作）\
  \* \@param p 目标节点（必须是有效节点）\
  \* \@param s 待插入的新节点（已分配内存，未接入链表）\
  \* \@return 成功返回true，失败返回false\
  \*/\
  bool InsertNextDNode(DNode \*p, DNode \*s) {\
  // 防御性检查：p或s为空，插入失败\
  if (p == NULL \|\| s == NULL) return false;\
  \
  //步骤的顺序绝对不能乱\
  // 步骤1：s的后继 指向 p的后继（先连后面，避免丢失链表）\
  s-\>next = p-\>next;\
  // 步骤2：如果p不是尾节点，p的后继节点的前驱 指向 s\
  if (p-\>next != NULL) {\
  p-\>next-\>prior = s;\
  }\
  // 步骤3：p的后继 指向 s（连接p和s）\
  p-\>next = s;\
  // 步骤4：s的前驱 指向 p（完成双向连接）\
  s-\>prior = p;\
  \
  return true;\
  }

  \* \@return 成功返回true，失败返回false\
  \*/\
  bool DeleteDNode(DNode \*p) {\
  // 防御性检查：p为空 或 p是头结点（头结点不允许删除）\
  if (p == NULL \|\| p-\>prior == NULL) return false;\
  \
  // 步骤1：让p的前驱节点的后继 指向 p的后继节点（断前驱→p的连接）\
  p-\>prior-\>next = p-\>next;\
  // 步骤2：如果p不是尾节点，让p的后继节点的前驱 指向 p的前驱节点（断p→后继的连接）\
  if (p-\>next != NULL) {\
  p-\>next-\>prior = p-\>prior;\
  }\
  // 步骤3：释放p的内存（避免内存泄漏）\
  free(p);\
  return true;\
  }

  C++\

  bool InitDList(DLinkList &L) {\
  L = (DNode \*)malloc(sizeof(DNode));\
  if (L == NULL) return false;\
  \
  // 循环双链表的初始化：头结点的prior和next都指向自己\
  L-\>prior = L;\
  L-\>next = L;\
  return true;\
  }

判空条件：L-\>next == L（或 L-\>prior == L）。头结点的 next 指向自己（等价于 prior 指向自己），无数据结点
