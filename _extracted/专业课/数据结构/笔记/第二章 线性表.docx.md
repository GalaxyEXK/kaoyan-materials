## 概念：

## 随机存取：

随机存取（Random Access）是指可以直接访问数据结构中的任意一个元素，且访问所需的时间与元素的位置无关（通常为 O(1) 时间复杂度）。

换句话说，只要知道元素的序号（索引），就能立即定位到它，而不需要从头开始逐个查找。

典型结构：顺序表、一维数组。

## 顺序存取：

顺序存取是指访问数据元素时，必须从第一个元素开始，按逻辑次序依次访问，才能找到目标元素。访问时间与元素的位置有关，平均时间复杂度为 O(n)。

换句话说，要访问第i个元素，必须先访问前i-1个元素，不能直接跳转。

典型结构：单链表、双链表。

## 散列存取：

散列存取是指通过散列函数（哈希函数），将元素的关键字直接计算出存储地址，从而直接访问元素。理想情况下，访问时间与元素个数、位置均无关，平均时间复杂度为 O(1)。

典型结构：哈希表（散列表）。

## 索引存取：

索引存取是指先通过一个索引表找到目标元素的实际存储地址，再根据地址访问元素。索引表中记录了关键字与元素位置的对应关系，先查索引、再取数据。访问效率取决于索引查找方式，通常比直接顺序查找更快。

典型结构：索引顺序表、数据库索引、文件索引结构。

## 存储密度:

存储密度是指数据本身占用的存储空间与节点总共占用的存储空间之比。简单来说，就是存储结构中有多大比例的空间是真正用来存数据的，而不是存辅助信息（如指针）的。

## 1. 什么叫“逻辑连续”？

线性表的逻辑结构是：

$$
a _ {1}, a _ {2}, a _ {3}, \dots , a _ {n}
$$

也就是说：

\- $a_{1}$ 是第一个元素；

\- $a_{i}$ 的直接后继是 $a_{i + 1}$ ;

\- $a_{i}$ 的直接前驱是 $a_{i - 1}$ ;

\- 除第一个元素外，每个元素有唯一前驱；

\- 除最后一个元素外，每个元素有唯一后继。

这叫逻辑连续。

注意：

逻辑连续说的是“谁在谁前面，谁在谁后面”，不是说内存地址挨着。

例如：

$$
A \to B \to C \to D
$$

只要逻辑关系是 A 后面是 B，B 后面是 C，C 后面是 D，就叫逻辑连续。

## 单链表的各种操作

## 一、带头结点 (Head Node)

## 1. 定义

带头结点的单链表：

在第一个“真正数据结点”之前，额外加一个结点（头结点），这个结点本身不存有效数据或只存辅助信息。

## 2. 结构

$$
\text {   head   } \rightarrow [ \text {   头结点   } ] \rightarrow [ \mathrm{A} ] \rightarrow [ \mathrm{B} ] \rightarrow [ \mathrm{C} ] \rightarrow \mathrm{NULL}
$$

\- head 指向的是“头结点”

\- 头结点不存数据（或不算有效数据）

\- 第一个有效结点是 A

## 3. 头结点特点

\- head != NULL (永远存在一个结点)

\- 空表时:

$$
\text {   head   } \rightarrow [ \text {   头结点   } ] \rightarrow \text {   NULL   }
$$

## 4. 作用（非常重要！）

## √ 统一操作逻辑

比如插入：

\- 插入第1个元素

\- 插入中间

\- 插入末尾

都可以用同一套代码处理，不需要单独处理“第一个结点”。

## 二、不带头结点

## 1. 定义

单链表没有额外头结点，head直接指向第一个数据结点。

## 2. 结构

head → [A] → [B] → [C] → NULL

## 3. 空表情况

head = NULL

## 4. 特点

\- 第一个结点就是数据结点

\- 插入/删除第一个结点时必须特殊处理

## 题目：

## 题1:

已知双向链表的结点结构包含 prior（前驱指针）、data（数据域）、next（后继指针），指针 p 指向双向链表中的某个结点（记为结点 A），p->next 指向结点 C。现要在结点 A 和结点 C 之间插入一个新结点 B（指针 q 指向结点 B），则正确的操作顺序是（）。

A. ① q->next = p->next; ② q->prior = p; ④ p->next->prior = q; ③ p->next = q;

B. ① q->next = p->next; ④ p->next->prior = q; ② q->prior = p; ③ p->next = q;

C. ③ p->next = q; ① q->next = p->next; ② q->prior = p; ④ p->next->prior = q;

D. ① q->next = p->next; ③ p->next = q; ④ p->next->prior = q; ② q->prior = p;

3. 为什么顺序是 ①②④③ (选项 A)

我们按顺序执行，看看每一步发生了什么：

1. ① $q->$ next = p->next;

\- 先把 B 的后继指针指向 C。这一步很关键，因为如果先修改了 A 的指针，我们就会丢失指向 C 的地址。

2. ② $q->$ prior = p;

把B的前驱指针指向A。现在B自己的前后指针都设置好了。

3. ④ p->next->prior = q;

\- 此时 p->next 仍然是 C，所以我们修改的是 C 的前驱指针，让它指向 B。

4. ③ p->next = q;

\- 最后修改A的后继指针，让它指向B。这一步完成后，A和B就连通了。

这样，四个指针就都正确修改完毕，链表结构变成了 A ⇔ B ⇔ C。
