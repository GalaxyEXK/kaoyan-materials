# 第三章 栈、队列和数组

## 栈

## 相关概念：

栈的核心操作需关注 “上溢” 和 “下溢” 两种异常情况，这是顺序栈实现中需重点规避的问题，具体概念如下：

上溢：当栈已满（以 top == -1 设计为例，栈满时 top == MaxSize - 1），仍尝试执行入栈操作，此时会导致栈元素溢出数组分配的内存空间，称为上溢，是一种致命错误，需在入栈操作中提前判断规避；

下溢：当栈为空（top == -1），仍尝试执行出栈或读取栈顶元素操作，此时无元素可操作，称为下溢，属于逻辑错误，同样需在对应操作中判断处理。

逻辑结构：指数据元素之间的相互关系，与数据的存储介质无关，仅描述数据元素的逻辑关联。对于栈而言，其逻辑结构为“先进后出”（LIFO，Last In First Out），即仅允许在一端（栈顶）进行插入和删除操作，数据元素的逻辑顺序由入栈顺序决定；对于队列而言，其逻辑结构为“先进先出”（FIFO，First In First Out），仅允许在一端（队尾）插入、另一端（队头）删除，数据元素的逻辑顺序与入队顺序一致。

存储结构：又称物理结构，指数据元素及其逻辑关系在计算机中的具体存储方式，直接影响数据操作的效率。常用的存储结构分为两种：顺序存储结构（如顺序栈、顺序队列），采用连续的内存空间存储数据元素，通过数组实现，访问效率高；链式存储结构（如链栈、链式队列），采用不连续的内存空间，通过指针链接各个数据元素，灵活度高，可动态分配内存。

## 队列

队列是先进先出（FIFO）的线性表，仅允许在「队尾（rear）」插入（入队）、「队头（front）」删除（出队）。

逻辑结构：始终是线性结构（元素一对一、有先后顺序）；

存储结构：分为「顺序存储」（顺序队列、循环队列）和「链式存储」（链式队列）。

```javascript
C++
#define MaxSize 5
// 队列的顺序存储结构（循环队列）
typedef struct {
    // 存储队列元素的数组
    int data[MaxSize];
    // 队头指针（指向队头元素）
    int front;
    // 队尾指针（指向队尾元素的下一个位置）
    int rear;
```

## 栈的应用：

栈的核心应用之一是表达式转换，其中中缀表达式转后缀表达式有多种方法，最直观的是括号法，具体方法如下（中缀转前缀是一样的思路）：

## 中缀表达式转后缀表达式的方法：

步骤：

1. 按照运算顺序给表达式加括号（遵循“先乘除、后加减，有括号先算括号内”的规则）；

1. 将每个运算符移到其对应括号的前面；

1. 去掉所有括号，得到的即为后缀表达式。

示例：A + B \* C

第 1 步：按运算顺序加括号

先算 B \* C（乘除优先级高于加减）：A + (B \* C)

再算 A + (B \* C): (A + (B \* C))

第 2 步：运算符移到对应括号的前面

$(A + (B * C)) \rightarrow + A (B * C)$

(B \* C) → \* B C

第 3 步：组合并去掉括号

\+ A \* B C

最终结果：+A\*BC

关键注意点

1. 转换的核心是利用栈“先进后出”的特性，临时存储运算符，实现优先级的有序处理，这也是栈在表达式计算中的核心价值。

1. 括号的处理是重点：转后缀时“遇左括号压栈，遇右括号弹栈到左括号”；转前缀时需先逆序括号，再按相反逻辑处理。

1. 后缀、前缀表达式的优势：无需考虑括号和优先级，仅通过栈即可从左到右（后缀）或从右到左（前缀）完成计算，是计算机处理表达式的核心方式。

## 题目：

1: 输入是 1, 2, 3, 4, 5，哪个输出既不能由输入受限的双端序列得到，又不能通过输出受限的双端序列得到

方法：

步骤 1：先判断是不是 普通队列 能输出的，用栈模拟 + 贪心：

能输出 $\rightarrow$ 合法

不能 $\rightarrow$ 进入下一步

步骤 2：判断能不能由 输入受限 双端队列输出

输入受限 = 只能尾部进，两头都能出等价于：可以从左边出，也可以从右边出本质 = 栈 + 队列的混合

判断规则（超级好用）：除了连续递减的一段，其余必须递增。简单记：

输入受限 = 允许一段逆序，其余必须递增

步骤 3：判断能不能由 输出受限 双端队列输出

输出受限 = 两头都能进，只能头部出等价于：可以左边插、右边插，但只能左边删本质 = 双端栈

判断规则：序列中不能出现“小 $\rightarrow$ 大 $\rightarrow$ 小”这种波浪形更简单的记法：

输出受限 = 最多一个上升点，不能反复升降

步骤 4：最终判断

如果一个序列：普通队列得不到，输入受限得不到，输出受限也得不到，则就是问题的答案。
